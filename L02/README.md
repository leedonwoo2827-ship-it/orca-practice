# 2강 · 업무를 봇에게 맡기는 법

**Orca로 일하는 법** · 1. 왜 Orca인가

- 이번 강에서 할 수 있게 되는 것: 목적·자료·형식·검토 기준이 담긴 요청문을 쓴다
- 실습 결과물: 요청문 3종

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `요청문틀_4요소.md`
- `자료_신입온보딩메모.md`
- `지시문_온보딩안내메일.md`

## 예시 결과 (`예시결과/`, 2개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

이번 주 실제 업무 1건을 골라 요청문 틀로 요청문을 쓰고, 한 줄 요청과 4칸 요청의 결과를 비교해 차이를 세 줄로 적으시오. (고객 정보·개인정보 파일은 자료로 넣지 않는다 — 3장)

> 영상에서는 이 파일들을 `D:\orca-practice\00-시작` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
신입 사원 온보딩 안내 메일 써 줘.
```

**메시지 2**

```text
[목적]
- 12월 1일 입사하는 신규 입사자 2명에게 보낼 첫날 안내 메일이다.
- 받는 사람은 회사가 처음이다. 읽고 나서 첫날 몇 시에 어디로 가고, 무엇을 챙기면 되는지 바로 알 수 있어야 한다.

[자료]
- 자료_신입온보딩메모.md 파일만 근거로 쓴다.

[형식]
- 파일 이름: 안내메일_신입온보딩.md
- 제목 1줄 + 본문. 본문은 인사 2줄, 첫날 일정 표, 준비물, 첫 주에 끝낼 일, 문의 순서.
- 정중하고 따뜻한 말투, 화면 한 장 분량.

[검토 기준]
- 메모에 없는 내용(주차, 식사 메뉴, 사람 이름 등)은 지어내지 않는다.
- 메모에서 "미정", "미확정"인 내용은 메일에 넣지 말고, 맨 아래 "보내기 전 확인 필요" 목록에 따로 적는다.
- 문의 메일 주소는 비워 두고 [주소 입력] 으로 표시한다.
```

**메시지 3**

```text
지시문_온보딩안내메일.md의 [검토 기준] 세 개로 방금 만든 안내메일_신입온보딩.md를 스스로 점검해서, 기준 / 통과 또는 위반 / 근거 문장 열로 표를 보여 줘. 파일은 고치지 마.
```

**메시지 4**

```text
요청문틀_4요소.md의 틀로 아래 업무 세 개의 요청문을 써서 요청문3종.md 파일로 저장해 줘.
1. 팀 회의 결과를 참석하지 못한 팀원에게 공유하는 메일
2. 다음 달 사내 교육 행사 준비물 점검표
3. 이번 주 내 업무 주간 보고
- 내가 알려 주지 않은 내용(날짜, 자료 파일 이름, 받는 사람 등)은 지어내지 말고 "확인 필요"로 비워 둬.
```
