# 요청문 3종 (요청문틀_4요소 적용)

> 각 요청문의 `확인 필요`는 아직 정해지지 않았거나 알려 주지 않은 칸입니다. **비운 채로 에이전트에 넣지 말고, 값을 채운 뒤 사용하세요.** 비워 두면 에이전트가 짐작으로 채웁니다.

---

## 1. 팀 회의 결과를 참석하지 못한 팀원에게 공유하는 메일

```text
[목적] 이 결과물을 누가, 어디에 쓰는가
- 회의에 참석하지 못한 팀원에게 메일로 보낸다.
- 받는 사람은 회의 내용을 전혀 모른다. 읽고 나서 무엇이 결정되었고 본인이 무엇을 해야 하는지 바로 알 수 있어야 한다.
- 받는 사람(이름·메일 주소): 확인 필요
- 회의 이름과 날짜: 확인 필요

[자료] 읽어야 할 파일 (파일 이름 정확히)
- 확인 필요 (회의록 또는 메모 파일 이름 — 폴더에 있는지, 이름이 정확한지 확인)
- 위 파일에 없는 내용은 쓰지 않는다.

[형식] 만들 파일 이름, 분량, 말투, 구성
- 파일 이름: 확인 필요 (예: 공유메일_팀회의결과.md)
- 제목 1줄 + 본문. 본문은 인사 1~2줄, 결정 사항, 담당자별 할 일 표, 다음 회의 안내, 문의 순서.
- 정중한 말투, 화면 한 장 분량.
- 문의 메일 주소는 [주소 입력]으로 비워 둔다.

[검토 기준] 결과가 통과하려면 지켜야 할 것
- 자료에 없는 내용은 지어내지 말고 "확인 필요"로 표시한다.
- 참석자 이름, 날짜, 수치는 자료에 적힌 그대로만 쓴다.
- 회의에서 결론이 나지 않은 안건은 본문에 결정된 것처럼 쓰지 말고, 맨 아래 "보내기 전 확인 필요" 목록에 따로 적는다.
- 할 일에는 담당자와 기한을 함께 적는다. 자료에 없으면 "확인 필요"로 둔다.
```

## 2. 다음 달 사내 교육 행사 준비물 점검표

```text
[목적] 이 결과물을 누가, 어디에 쓰는가
- 행사 준비 담당자가 행사 전에 하나씩 짚어 보며 쓴다.
- 인쇄하거나 화면에 띄워 놓고, 빠진 준비물이 없는지 체크하는 용도다.
- 행사 이름과 날짜: 확인 필요
- 참석 인원과 장소: 확인 필요

[자료] 읽어야 할 파일 (파일 이름 정확히)
- 확인 필요 (지난 행사 준비 메모 또는 행사 기획안 파일 이름)
- 참고할 파일이 없다면, 자료 없이 쓰지 말고 먼저 자료부터 확인한다.

[형식] 만들 파일 이름, 분량, 말투, 구성
- 파일 이름: 확인 필요 (예: 점검표_사내교육행사.md)
- 표 하나로 만든다. 열은 구분 / 준비물 / 수량 / 담당 / 준비 기한 / 상태.
- 구분은 장소·장비, 인쇄물, 다과, 기타 순서로 묶는다.
- 담백한 말투, 화면 한 장 분량.

[검토 기준] 결과가 통과하려면 지켜야 할 것
- 자료에 없는 내용은 지어내지 말고 "확인 필요"로 표시한다.
- 수량, 담당자, 기한을 추측해서 채우지 않는다.
- 자료에 없지만 빠지면 안 될 것 같은 항목은 표 아래 "추가 검토 항목"에 따로 적고, 표 안에 섞지 않는다.
- 상태 열은 모두 비워 둔 채로 만든다 (담당자가 직접 체크).
```

## 3. 이번 주 내 업무 주간 보고

```text
[목적] 이 결과물을 누가, 어디에 쓰는가
- 보고 받는 사람: 확인 필요 (팀장 / 전체 공유 등)
- 받는 사람은 내 업무를 매일 보고 있지는 않다. 이번 주에 무엇이 끝났고 무엇이 막혀 있는지 짧게 파악할 수 있어야 한다.
- 보고 대상 기간(시작일~종료일): 확인 필요

[자료] 읽어야 할 파일 (파일 이름 정확히)
- 확인 필요 (업무 기록, 할 일 목록, 또는 지난주 보고 파일 이름)
- 기억이나 짐작이 아니라 위 파일에 적힌 것만 쓴다.

[형식] 만들 파일 이름, 분량, 말투, 구성
- 파일 이름: 확인 필요 (예: 주간보고_YYYYMMDD.md)
- 구성: 이번 주 한 일, 다음 주 할 일, 막힌 일·도움 필요한 것 순서.
- 각 항목은 한 줄씩, 항목별 5개 이내.
- 간결한 보고체, 화면 한 장 분량.

[검토 기준] 결과가 통과하려면 지켜야 할 것
- 자료에 없는 내용은 지어내지 말고 "확인 필요"로 표시한다.
- 진행률(%)과 완료 여부는 자료에 적힌 것만 쓰고, 추정해서 올리거나 내리지 않는다.
- "막힌 일"에는 무엇이 필요한지(누구의 결정, 어떤 자료)를 함께 적는다.
- 아직 시작하지 않은 일을 "진행 중"으로 쓰지 않는다.
```

## 쓰기 전 채워야 할 칸 (공통)

| 요청문 | 비워 둔 칸 |
|---|---|
| 1. 회의 결과 공유 메일 | 받는 사람, 회의 이름·날짜, 회의록 파일 이름, 결과 파일 이름 |
| 2. 행사 준비물 점검표 | 행사 이름·날짜, 참석 인원·장소, 참고 자료 파일 이름, 결과 파일 이름 |
| 3. 주간 보고 | 보고 받는 사람, 보고 기간, 업무 기록 파일 이름, 결과 파일 이름 |
