# 설치 점검표 (4강)

각 항목을 확인하고 "결과" 칸을 채운다. 확인 방법에 적힌 명령은 PowerShell에서 실행한다.

| 번호 | 항목 | 확인 방법 | 결과 |
|---|---|---|---|
| 1 | Git for Windows 설치 | `git --version` 실행 시 버전이 나온다 | |
| 2 | Claude Code 설치 | `claude --version` 실행 시 버전이 나온다 | |
| 3 | Claude Code 로그인 | `claude` 실행 후 로그인 안내 없이 입력창이 뜬다 | |
| 4 | Orca 설치 | 시작 메뉴에서 Orca가 실행된다 | |
| 5 | Orca 기본 셸 | Orca 설정 → Terminal → 기본 셸이 PowerShell이다 | |
| 6 | 실습 저장소 | `D:\orca-practice\00-시작` 폴더가 있고 git 저장소다 (`git status`가 오류 없이 실행된다) | |
| 7 | Orca에서 저장소 열기 | Orca 파일 목록에 시작하기.md가 보인다 | |
| 8 | 첫 채팅 | Claude Code가 "이 폴더에 뭐가 있어?"에 답한다 | |

## 막힐 때

| 증상 | 먼저 볼 곳 |
|---|---|
| `git`을 찾을 수 없다 | Git for Windows 설치 후 PowerShell 창을 새로 열었는가 |
| `claude`를 찾을 수 없다 | 설치 후 PowerShell 창을 새로 열었는가 |
| Orca에서 에이전트가 응답하지 않는다 | PowerShell에서 `claude`를 실행해 로그인 상태를 확인한다 |
| 워크트리 관련 오류 | 연 폴더가 git 저장소인가, Git for Windows가 설치됐는가 |
