# 4강 · Orca 설치와 첫 채팅

**Orca로 일하는 법** · 1. 왜 Orca인가

- 이번 강에서 할 수 있게 되는 것: Orca를 설치하고 클로드 코드를 연결해 첫 채팅을 보낸다
- 실습 결과물: 설치 완료 화면

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `설치점검표.md`
- `시작하기.md`

## 예시 결과 (`예시결과/`, 1개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

내 PC에 Git·Claude Code·Orca를 설치하고 `설치점검표_완료.md`의 8개 항목을 모두 채우시오. 막힌 항목이 있었다면 원인과 해결 방법을 한 줄씩 적으시오.

> 영상에서는 이 파일들을 `D:\orca-practice\00-시작` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
안녕, 이 폴더에 뭐가 있어? 파일은 고치지 마.
```

**메시지 2**

```text
시작하기.md를 읽고, 이 과정에서 처음 할 일 세 가지를 번호 목록으로 알려 줘. 파일은 고치지 마.
```

**메시지 3**

```text
설치점검표.md의 항목 중에서 네가 명령으로 직접 확인할 수 있는 것만 확인해서, 결과 칸을 채운 설치점검표_완료.md를 새로 만들어 줘.
- 확인할 때 실행한 명령과 결과(버전 번호 등)를 결과 칸에 적어 줘
- 네가 볼 수 없는 항목(Orca 화면 설정 등)은 "사람이 확인"이라고 적어 줘
- 설치점검표.md 원본은 고치지 마
```
