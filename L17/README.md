- 실습 결과물: 다국어 메일

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 과제

내 업무에서 자주 쓰는 용어 10개로 용어집 CSV를 만들고, 최근 메일 1통(이름·연락처 삭제)을 번역한 뒤 역번역 점검표를 만드시오.

> 영상에서는 이 파일들을 `D:\orca-practice\03-해외사업` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
L17_파트너메일_수신.md 를 읽고 한국어로 요점을 정리해서 받은메일_요약_0412.md 로 저장해 줘.

- 3줄 요약
- 상대가 요청한 것 목록 (번호, 요청 내용, 원문 문장)
- 우리가 답해야 할 것과 기한. 메일에 기한이 없으면 "기한 없음"으로 쓴다
- 메일에 없는 내용은 추측하지 마
```

**메시지 2**

```text
L17_답장초안_한글.md 를 영어 메일로 번역해서 답장_영문.md 로 저장해 줘.

[지켜야 할 것]
- 용어는 L17_용어집.csv 를 반드시 따른다. 용어집에 있는 한국어가 나오면 그 영어만 쓴다
- 용어집의 "비고" 칸(첫 등장 때 전체 이름, 쓰지 않을 단어)도 지킨다
- 톤은 정중한 공식 업무 메일. 축약형(I'm, we'll)과 느낌표를 쓰지 않는다
- 날짜는 "24 May 2027"처럼 일·월·연 순서로 쓴다
- 원문에 없는 약속이나 사과, 인사를 덧붙이지 않는다
- 번역문 아래에 "용어집 적용 목록" 표를 붙인다 (한국어, 쓴 영어, 용어집 줄)
```

**메시지 3**

```text
답장_영문.md 를 다시 한국어로 옮긴 다음, L17_답장초안_한글.md 와 문장별로 비교해서 역번역점검_답장.md 로 저장해 줘.

- 열: 번호, 원문(한국어), 영문, 역번역(한국어), 판정, 설명
- 판정은 "같음 / 뜻 달라짐 / 용어집 위반 / 톤 문제" 중 하나
- 특히 약속·확정 정도("검토 중", "하겠습니다", "부탁드립니다")가 바뀌었는지 본다
- 답장_영문.md 는 고치지 마
```

**메시지 4**

```text
역번역 점검에서 뜻 달라짐입니다. 아직 결정되지 않았다(내부 검토 중)는 뜻이 분명하게 드러나도록 고쳐 주세요. "5월 첫 주에 답을 드린다"는 내용은 그대로 두세요.
```

**메시지 5**

```text
수정된 답장_영문.md 로 역번역점검_답장.md 를 다시 만들어 줘. 답장은 고치지 마.
```

**메시지 6**

```text
L17_진행보고_한글.md 를 L17_번역지시문.md 와 같은 규칙으로 영문 보고서로 번역해서 진행보고_영문_2027-04.md 로 저장해 줘.

- 보고서 문체로 쓰고, 표는 표로 유지한다
- 맨 아래에 "자가 점검" 표를 붙인다: 용어집 위반 여부, 원문과 숫자(과정 수, 인원, 날짜)가 같은지
```
