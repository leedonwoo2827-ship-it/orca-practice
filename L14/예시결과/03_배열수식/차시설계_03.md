# 3차시 설계: 배열 수식으로 조건 집계하기

## 1. 계획서 근거
| 항목 | 내용 (강의계획서 3행 그대로) |
|---|---|
| 시험 영역 | 계산작업 |
| 차시명 | 배열 수식으로 조건 집계하기 |
| 학습목표 | 조건이 둘 이상인 합계·개수·평균을 배열 수식으로 계산할 수 있다 |
| 핵심 기능 | 배열 수식(SUM·IF 조합), 조건 곱하기, MAX·IF |
| 실습 파일 / 정답 파일 | 실습_03_배열수식.xlsx / 정답_03_배열수식.xlsx |

## 2. 예제 계획 (대본 시연용 2개)
| 예제 | 다룰 기능 | 데이터 범위 | 결과 예시 |
|---|---|---|---|
| 1 | SUM·IF 중첩 → 같은 답을 조건 곱하기로 바꿔 쓰기, Ctrl+Shift+Enter | B2:B21, D2:D21, F2:F21 → I2 | 강북 지점 가전 상품군 매출액 합계 = 3,920 |
| 2 | MAX·IF 조합 (조건을 만족하는 행 중 최대값) | D2:D21, E2:E21 → I5 | 생활 상품군의 최대 판매수량 = 55 |

- 예제 1은 문항 1과, 예제 2는 문항 4와 같은 문제다. 2차시 본보기와 같이 "시연에서 본 두 개 + 스스로 풀 문제"를 한 실습 파일에 담는다.
- 예제 1에서 조건 곱하기 형태 `=SUM((B2:B21="강북")*(D2:D21="가전")*F2:F21)`를 함께 보여 주되, 개수 세기(문항 2)는 실습으로 넘긴다.

## 3. 가상 데이터 설계 (데이터_03.csv)
- 주제: 가상 유통사의 지점별 분기 판매 실적표 (사람 정보 없음, 지점·상품군·수량·금액만)
- 열 구성: 주문번호 / 지점 / 분기 / 상품군 / 판매수량 / 매출액 (매출액 단위: 만원)
  - 지점 4종: 강북, 강남, 수원, 대전
  - 상품군 4종: 가전, 가구, 주방, 생활
  - 분기: 1~4
- 행 수: 20행 (A2:F21). 시트 이름 `판매실적`, 요약표는 H1:I6
- 일부러 넣은 경계값·예외
  - **대전 지점에는 가구 상품군 주문이 한 건도 없다** → 조건 두 개 합계는 0, 같은 조건의 평균은 나누기 오류가 난다. 개념에서 "조건에 맞는 행이 없을 때"를 설명하는 근거.
  - 판매수량 경계: 강남 주방(S-010)이 18개라서 "20개 이상" 조건(문항 5)에서 **빠진다**. 주방 중 유일하게 빠지는 행.
  - 강북 가전(S-011)이 정확히 20개 → "20 이상"에 **들어간다**(크거나 같다 확인용). 단, 상품군이 주방이 아니라 문항 5에는 안 들어간다.
  - 수량이 큰 행(생활 55개)과 금액이 큰 행(가전 1,600)이 서로 달라 "수량 최대 ≠ 금액 최대"를 보여 준다.
  - 수원 주방은 25, 28 두 건뿐이라 평균이 26.5로 소수가 나온다 → 반올림(문항 3) 근거.

## 4. 실습 문항 계획 (3~5문항)
| 번호 | 유형 | 함수/기능 | 난이도 |
|---|---|---|---|
| 1 | 조건 두 개 합계 (지점+상품군) | SUM·IF 배열 수식 | 중 |
| 2 | 조건 두 개 개수 (지점+분기) | 조건 곱하기 SUM | 하 |
| 3 | 조건 두 개 평균 + 반올림 (지점+상품군) | AVERAGE·IF 배열 수식, ROUND | 중 |
| 4 | 조건 한 개 최대값 (상품군) | MAX·IF 배열 수식 | 중 |
| 5 | 문자 조건 + 숫자 조건 합계 (상품군+수량 기준) | 조건 곱하기 SUM | 상 |

- 답 셀은 요약표 I2:I6 한 칸씩. 모두 Ctrl+Shift+Enter로 입력하는 배열 수식 (문항 2·5의 조건 곱하기 형태도 시험 기준대로 배열 입력으로 통일).
- 핵심 기능 세 가지(SUM·IF 조합 / 조건 곱하기 / MAX·IF)가 각각 1·3번, 2·5번, 4번에 들어간다.

## 5. 가정한 것 / 확인 필요
- **가정**: 매출액 단위를 "만원"으로 정했다. 계획서에 단위 지정이 없어 표 머리글과 문제 문장에 "(만원)"을 명시했다.
- **가정**: 요약표 위치를 H1:I6으로 정했다. 계획서에 답 셀 위치 지정이 없어 2차시 본보기(보조표를 L열에 둔 방식)를 따라 표 오른쪽 한 칸을 비우고 배치했다.
- **가정**: 문항 2·5는 조건 곱하기로도 Ctrl+Shift+Enter 없이 계산되지만, 시험 답안 표기를 통일하려고 배열 수식으로 입력하도록 안내했다.
- **확인 필요**: 시험 기준 버전(Microsoft Office 2021 여부) — 2021 이후 버전은 배열 수식을 Ctrl+Shift+Enter 없이 그냥 Enter로도 계산한다. 어느 쪽을 기준으로 가르칠지 사람이 정해야 한다. 대본은 "Ctrl+Shift+Enter로 입력한다"로 썼다.
- **확인 필요**: 계산작업 배점·문항 수는 계획서 5절대로 기획 참고값이라 대본에서 말하지 않았다.
- **확인 필요**: SUM·MAX의 낭독 표기가 발음 사전에 없다. 대본에는 "섬", "맥스"로 썼다. 사전은 고치지 않았다 (사람이 정한다).
