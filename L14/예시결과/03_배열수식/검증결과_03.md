# 3차시 검증 결과

생성 스크립트: `make_xlsx_03.py` (openpyxl 3.1.5, Python 3.12.7)
대상 파일: `실습_03_배열수식.xlsx` / `정답_03_배열수식.xlsx` (시트 `판매실적`, 표 A1:F21, 요약표 H1:I6)

## 1. 정답 파일을 다시 열어 읽은 수식 목록

정답 파일을 `load_workbook`으로 다시 열어 읽은 값입니다. 다섯 칸 모두 **값이 아니라 배열 수식(ArrayFormula)** 으로 들어 있고, `문항_03.json`의 정답 수식과 글자까지 일치했습니다.

| 답 셀 | 종류 | 읽어 온 수식 | JSON과 대조 |
|---|---|---|---|
| I2 | 배열 수식 | `=SUM(IF(B2:B21="강북",IF(D2:D21="가전",F2:F21)))` | 일치 |
| I3 | 배열 수식 | `=SUM((B2:B21="강남")*(C2:C21=2))` | 일치 |
| I4 | 배열 수식 | `=ROUND(AVERAGE(IF(B2:B21="수원",IF(D2:D21="주방",E2:E21))),1)` | 일치 |
| I5 | 배열 수식 | `=MAX(IF(D2:D21="생활",E2:E21))` | 일치 |
| I6 | 배열 수식 | `=SUM((D2:D21="주방")*(E2:E21>=20)*F2:F21)` | 일치 |

실습 파일의 같은 칸은 다시 열어 읽었을 때 모두 `None`(빈 칸)이었습니다.

## 2. 파이썬으로 따로 계산한 기대값

엑셀 수식과 무관하게 `데이터_03.csv`를 파이썬으로 직접 집계한 값입니다.

| 답 셀 | 조건 | 해당 행 | 기대값 |
|---|---|---|---|
| I2 | 지점 강북 + 상품군 가전 | S-001(960), S-011(1600), S-019(1360) | **3920** |
| I3 | 지점 강남 + 분기 2 | S-006, S-010 | **2** |
| I4 | 지점 수원 + 상품군 주방 | S-003(25), S-020(28) → 평균 26.5 | **26.5** |
| I5 | 상품군 생활의 판매수량 최대 | S-004(40), S-009(55), S-012(35), S-017(48) | **55** |
| I6 | 상품군 주방 + 판매수량 20 이상 | S-003(375), S-007(450), S-018(330), S-020(420) <br> ※ S-010은 18개라 제외 | **1575** |

### 경계값·예외 확인
- 대전 지점 + 가구 상품군: **해당 행 0건**. 같은 꼴의 합계 수식은 0, 평균 수식은 `#DIV/0!`이 납니다. 대본 시연 단계 5에서 이 조합을 씁니다.
- I6의 "20 이상" 경계: 강남 주방(S-010)이 18개라 제외되고, 강북 가전(S-011)은 정확히 20개지만 상품군이 주방이 아니라 역시 제외됩니다.

## 3. openpyxl로는 확인할 수 없는 것

openpyxl은 수식을 **계산하지 않고 글자 그대로 저장**합니다. 따라서 위 기대값은 파이썬 계산 결과일 뿐, 엑셀이 실제로 그 값을 내는지는 확인하지 못했습니다. 아래 칸은 사람이 엑셀에서 직접 확인해야 합니다.

## 4. 엑셀에서 직접 확인할 셀

`정답_03_배열수식.xlsx`를 엑셀에서 열고, 각 칸을 선택해 **수식 입력줄 양 끝에 중괄호가 보이는지**와 **표시된 값**을 확인하세요.

- [ ] `I2` → 3920 / 중괄호 있음
- [ ] `I3` → 2 / 중괄호 있음
- [ ] `I4` → 26.5 / 중괄호 있음 (표시 형식 0.0 적용 확인)
- [ ] `I5` → 55 / 중괄호 있음
- [ ] `I6` → 1575 / 중괄호 있음
- [ ] `실습_03_배열수식.xlsx`의 `I2:I6`이 빈 칸인지, 표(A1:F21)와 요약표 라벨(H2:H6)은 그대로인지
- [ ] 두 파일 모두 표 머리글이 1행에 있고 데이터가 21행에서 끝나는지 (범위 길이 20행 확인)

> 확인 필요: Microsoft Office 2021 이후 버전은 배열 수식을 그냥 Enter로 입력해도 계산되고, 이때 중괄호가 보이지 않습니다. 중괄호가 없다고 틀린 것은 아니므로, **어느 버전을 기준으로 가르칠지 사람이 정해야 합니다**. 대본은 Ctrl+Shift+Enter 기준으로 썼습니다.
