# 3차시 실습 문항: 배열 수식으로 조건 집계하기

> 시험영역: 계산작업 · 모든 문항 출처: 자사 재집필 (기출 원문 없음)
> 이 파일은 `문항_03.json`에서 생성했습니다. 내용을 고칠 때는 JSON을 먼저 고칩니다.

## 데이터

| 항목 | 내용 |
|---|---|
| 시트 | 판매실적 |
| 표범위 | A1:F21 |
| 요약표범위 | H1:I6 |
| 원본파일 | 데이터_03.csv |
| 비고 | 가상 자료 (가상 유통사 지점별 판매 실적, 매출액 단위 만원) |

## 문항

| 번호 | 유형 | 답 셀 | 사용 함수 | 난이도 |
|---|---|---|---|---|
| 1 | SUM·IF 배열 수식 (조건 두 개 합계) | I2 | SUM, IF | 중 |
| 2 | 조건 곱하기 (조건 두 개 개수) | I3 | SUM | 하 |
| 3 | AVERAGE·IF 배열 수식 + ROUND | I4 | ROUND, AVERAGE, IF | 중 |
| 4 | MAX·IF 배열 수식 (조건 한 개 최대값) | I5 | MAX, IF | 중 |
| 5 | 조건 곱하기 (문자 조건 + 숫자 조건 합계) | I6 | SUM | 상 |

### 1번 (중)

**문제**  지점이 "강북"이면서 상품군이 "가전"인 주문의 매출액 합계를 [I2]에 표시하시오. (단, SUM 함수와 IF 함수를 사용한 배열 수식으로 작성하시오.)

| 항목 | 내용 |
|---|---|
| 답 셀 | `I2` |
| 정답 수식 | `=SUM(IF(B2:B21="강북",IF(D2:D21="가전",F2:F21)))` |
| 입력 방법 | Ctrl+Shift+Enter로 배열 입력 |
| 사용 함수 | SUM, IF |
| 출처 | 자사 재집필 |
| 검토 메모 | 기대값: 3920 (S-001 960 + S-011 1600 + S-019 1360). 대본 시연 예제 1과 같은 문제. |

### 2번 (하)

**문제**  지점이 "강남"이면서 분기가 2인 주문의 건수를 [I3]에 표시하시오. (단, 조건을 곱하는 배열 수식으로 작성하시오.)

| 항목 | 내용 |
|---|---|
| 답 셀 | `I3` |
| 정답 수식 | `=SUM((B2:B21="강남")*(C2:C21=2))` |
| 입력 방법 | Ctrl+Shift+Enter로 배열 입력 |
| 사용 함수 | SUM |
| 출처 | 자사 재집필 |
| 검토 메모 | 기대값: 2 (S-006, S-010). 분기는 숫자라 큰따옴표 없이 비교한다. |

### 3번 (중)

**문제**  지점이 "수원"이면서 상품군이 "주방"인 주문의 판매수량 평균을 소수 첫째 자리까지 반올림하여 [I4]에 표시하시오. (단, AVERAGE 함수와 IF 함수를 사용한 배열 수식으로 작성하시오.)

| 항목 | 내용 |
|---|---|
| 답 셀 | `I4` |
| 정답 수식 | `=ROUND(AVERAGE(IF(B2:B21="수원",IF(D2:D21="주방",E2:E21))),1)` |
| 입력 방법 | Ctrl+Shift+Enter로 배열 입력 |
| 사용 함수 | ROUND, AVERAGE, IF |
| 출처 | 자사 재집필 |
| 검토 메모 | 기대값: 26.5 (S-003 25, S-020 28). 표시 형식을 0.0으로 지정해 둠. |

### 4번 (중)

**문제**  상품군이 "생활"인 주문 중 판매수량의 최대값을 [I5]에 표시하시오. (단, MAX 함수와 IF 함수를 사용한 배열 수식으로 작성하시오.)

| 항목 | 내용 |
|---|---|
| 답 셀 | `I5` |
| 정답 수식 | `=MAX(IF(D2:D21="생활",E2:E21))` |
| 입력 방법 | Ctrl+Shift+Enter로 배열 입력 |
| 사용 함수 | MAX, IF |
| 출처 | 자사 재집필 |
| 검토 메모 | 기대값: 55 (S-009). 대본 시연 예제 2와 같은 문제. |

| 항목 | 내용 |
|---|---|

| 사용 함수 | SUM |
| 출처 | 자사 재집필 |
