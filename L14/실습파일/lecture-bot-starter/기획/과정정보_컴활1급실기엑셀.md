# 과정 기본정보 (가상 실습 자료)

> 이 파일은 실습용 가상 기획 메모입니다. 시험 구성·배점은 기획 참고값이며, 강의 확정 전 대한상공회의소 공고로 반드시 다시 확인합니다.

- 과정명: 컴활 1급 실기 스프레드시트 특강
- 요청: 자격증 사업팀 → 과정개발팀
- 대상: 컴활 1급 필기 합격자. 엑셀 기본 기능은 쓸 수 있으나 함수 중첩·VBA 경험은 거의 없음
- 운영 방식: 온라인 동영상 + 실습 파일, LMS 수강
- 분량: 10차시, 차시당 15분 영상 + 실습 15분
- 시험 기준 버전: Microsoft Office 2021 `[확인 필요: 시행처 공고]`
- 시험 구성(스프레드시트 실무, 기획 참고값)
  | 영역 | 주요 내용 | 배점 |
  |---|---|---|
  | 기본작업 | 고급 필터, 조건부 서식, 페이지 설정·시트 보호 | 15 |
  | 계산작업 | 함수(중첩·배열 수식), 사용자 정의 함수(VBA) | 30 |
  | 분석작업 | 피벗 테이블, 데이터 표·시나리오·목표값 찾기·통합·유효성 검사 | 20 |
  | 기타작업 | 차트 수정, 매크로, VBA 프로시저(폼·이벤트) | 35 |
  - 합격 기준: 100점 만점에 70점 이상
- 요구사항
  1. 영역별 차시 수가 배점 비중에 맞을 것
  2. 차시마다 실습 파일과 정답 파일을 함께 제공할 것
  3. 기출문제 원문은 쓰지 않고, 개념만 살려 자사가 새로 쓴 문제만 쓸 것
  4. 마지막 차시는 자사 모의고사 1회분 풀이로 할 것
- 제약
  - 시험 기준 버전에 없는 기능은 다루지 않음
  - 매크로·VBA 실습 파일은 매크로 사용 통합 문서(.xlsm)로 제공
