# 실습 문항 검토 체크리스트

- [ ] 문항이 3~5개이고, 차시의 핵심 기능을 모두 다루는가
- [ ] 문항마다 답 셀, 정답 수식, 사용 함수, 난이도, "출처": "자사 재집필"이 있는가
- [ ] 문제 문장에 결과 표시 문구와 형식이 분명히 적혀 있는가 (모호한 조건 없음)
- [ ] 문항_NN.md와 문항_NN.json의 내용이 같은가
- [ ] 정답 파일의 답 칸에 값이 아니라 수식이 들어 있는가
- [ ] 실습 파일의 답 칸이 비어 있는가
- [ ] 검증결과_NN.md에 수식 목록·기대값·엑셀에서 확인할 셀 목록이 있는가
- [ ] 데이터가 가상 자료이고 실제 개인정보처럼 보이지 않는가
- [ ] 기출문제 원문 인용·흉내가 없는가 ← **사람이 직접 확인**
- [ ] 엑셀에서 열어 값이 기대값과 같은가 ← **사람이 직접 확인**
