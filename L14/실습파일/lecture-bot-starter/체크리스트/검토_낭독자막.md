# 낭독본·자막 검토 체크리스트

- [ ] 낭독본에 제목·큐 줄·메모 줄이 없고 한 줄에 한 문장인가
- [ ] 낭독본의 문장 내용이 대본과 같은가 (표기만 바뀜)
- [ ] 발음 사전이 적용되었고, 사전에 없어 남은 표기가 목록으로 보고되었는가
- [ ] 자막은 화면 표기(함수 이름·셀 주소 원래 모양)로 되어 있는가
- [ ] 자막 한 개는 최대 두 줄, 한 줄 20자 안팎인가
- [ ] 자막 시각이 초당 4.8자 기준으로 계산되었고 전체 예상 길이가 보고되었는가
- [ ] 음성은 사람이 만들고 들어서 확인했는가 ← **사람이 직접 확인**
