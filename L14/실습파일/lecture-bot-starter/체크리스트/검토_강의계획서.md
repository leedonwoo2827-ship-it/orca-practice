# 강의계획서 검토 체크리스트 

- [ ] 과정 목표가 "~할 수 있다"로 끝나고, 관찰 가능한 동사(작성한다, 계산한다, 만든다)를 쓰는가
- [ ] 차시가 정확히 10개인가
- [ ] 영역별 차시 수가 배점 비중에 맞는가 (기타작업 35 > 계산작업 30 > 분석작업 20 > 기본작업 15)
- [ ] 차시마다 실습 파일과 정답 파일이 모두 있는가 (매크로·VBA 차시는 .xlsm)
- [ ] 마지막 차시가 자사 모의고사 1회분 풀이인가
- [ ] 기출문제 원문 인용이나 흉내가 없는가
- [ ] 시험 기준 버전에 없는 기능이 들어 있지 않은가
- [ ] 과정정보에 없는 내용이 사실처럼 적혀 있지 않은가 ("확인 필요" 목록 확인)
