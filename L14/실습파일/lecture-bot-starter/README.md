# lecture-bot-starter — 강의 제작 봇 시작 저장소

「컴활 1급 실기 스프레드시트 특강」의 차시를 **강의계획서 한 줄 → 차시 설계 → 대본 → 실습 문제 → 실습·정답 엑셀 → 낭독본·자막 → 점검**까지 한 번에 만드는 Orca 봇용 저장소입니다.
『Orca로 일하는 법 — 에이전트와 함께하는 실무』 10~13강에서 채팅으로 한 단계를 하나로 묶었습니다. 모든 데이터는 가상 자료입니다.

## 1. 받기 (clone)

```powershell
# 실제 GitHub 저장소
git clone https://github.com/<계정>/lecture-bot-starter.git D:\orca-practice\lecture-bot

# 강의 실습용 (인터넷 없이, setup-practice.ps1이 만든 로컬 저장소)
git clone D:\orca-practice\_remote\lecture-bot-starter.git D:\orca-practice\lecture-bot
```

- 주소는 GitHub 저장소 화면의 **Code** 단추 → **HTTPS** 탭에서 복사합니다.
- 비공개 저장소는 GitHub 로그인이 필요합니다. 처음 clone할 때 로그인 창이 뜨면 로그인합니다.

## 2. 봇 만들기 (Orca)

1. Orca에서 `D:\orca-practice\lecture-bot` 폴더를 프로젝트로 엽니다. `[화면 확인]`
2. 사이드바 **Bots** → **+** → **New bot** → **Start from scratch**.
3. 이름 `강의제작봇`, 설명 "강의계획서의 차시 번호를 주면 차시 자료 일체를 만든다", 컴퓨터는 이 PC, 에이전트는 Claude Code, 작업 폴더는 `D:\orca-practice\lecture-bot` `[화면 확인]` → **Create**.
4. 봇 채팅창에 `3차시 만들어 줘`라고 보냅니다.

> 봇은 이 컴퓨터가 켜져 있고 온라인일 때만 일합니다. 꺼져 있는 동안 들어온 요청은 최대 하루까지 기다립니다.

## 3. 폴더 구조

| 경로 | 내용 | 누가 고치나 |
|---|---|---|
| `CLAUDE.md` | Claude Code가 작업을 시작할 때 자동으로 읽는 파일. 봇지시문으로 안내 | 사람 |
| `AGENTS.md` | Codex 등 다른 에이전트용 같은 안내 | 사람 |
| `봇지시문.md` | 봇이 따르는 작업 순서와 규칙 (10~13강 단계) | 사람 |
| `기획/` | 과정 정보, 강의계획서 (봇의 근거 자료) | 사람 |
| `규칙/` | 낭독 표기 규칙, 발음 사전 | 사람 (봇은 추가 제안만) |
| `체크리스트/` | 강의계획서·대본·문항·낭독자막 검토 항목 | 사람 |
| `templates/` | 차시 설계, 대본, 문항, 점검 결과 양식 | 사람 |
| `examples/02_함수중첩/` | 사람이 검토를 마친 2차시 본보기 | 사람 |
| `차시/` | 봇이 만드는 결과물 (`차시/NN_이름/`) | 봇 |

## 4. 지켜야 할 것
- 기출문제 원문은 넣지 않습니다. 모든 문제는 자사 재집필입니다.
- 실제 학습자·고객 정보는 넣지 않습니다.
- 봇지시문·체크리스트를 바꾸면 **커밋한 뒤** 봇에게 요청합니다. 봇의 작업용 워크트리는 커밋된 내용에서 만들어집니다.
