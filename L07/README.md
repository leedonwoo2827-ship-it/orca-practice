# 7강 · 병렬 채팅: 3안 받아 고르기

**Orca로 일하는 법** · 2. 업무 채팅 기본기

- 이번 강에서 할 수 있게 되는 것: 같은 요청을 여러 에이전트에 보내 결과를 비교·선택한다
- 실습 결과물: 공지문 비교표

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `L07_공지문_비교기준.md`
- `L07_공지요청메모.md`
- `L07_지시문_공지문.md`

## 예시 결과 (`예시결과/`, 2개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

최근 써야 했던 공지·안내문 1건으로 요청 메모를 만들고, 워크트리 세 개로 세 안을 받아 부서에 맞게 고친 기준표로 비교하시오.

> 영상에서는 이 파일들을 `D:\orca-practice\01-업무채팅` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
L07_공지요청메모.md 를 읽고 전 직원에게 보낼 사내 공지문을 써 줘.

[만들 파일]
- 파일 이름: 공지문_공유폴더정리주간.md

[들어갈 내용]
1. 제목 한 줄
2. 본문: 인사 한 줄, 왜 하는지, 기간, 직원이 할 일(번호 목록), 끝난 뒤 일정, 문의처
3. 본문은 600자 이내

[지켜야 할 것]
- 날짜, 요일, 연락처는 메모에 적힌 그대로 쓴다.
- 메모에 없는 내용(경품, 벌칙, 마감 시각 등)은 지어내지 않는다.
- 메모의 요청 사항 세 가지(말투, 길이, 겁주는 표현 금지)를 지킨다.
- 다 쓰면 본문 글자 수를 채팅으로 알려 줘.
```

**메시지 2**

```text
L07_공지문_비교기준.md 의 다섯 기준으로 네가 쓴 공지문을 점검해서 기준마다 ○△× 와 근거를 한 줄씩 답해 줘. 파일은 고치지 마.
```

**메시지 3**

```text
세 안을 비교한 내 판단을 공지문_비교표.md 로 정리해 줘. L07_공지문_비교기준.md 의 비교표 형식을 쓰고, 칸마다 ○△× 와 한 줄 근거를 적어 줘.
- A안: 사실 정확(○), 할 일 분명(○), 조금 길다(△), 말투 무난(○), 제목 평범(△)
- B안: 사실 정확(○), 할 일 번호 목록으로 분명(○), 길이 적당(○), 말투 가장 부드러움(○), 질문형 제목(○)
- C안: 메모에 없는 마감 시각을 넣음(×), 할 일 표로 분명(○), 가장 짧음(○), 말투 무난(○), 제목 무난(○)
- 선택: B안. 이유: 사실이 정확하고 말투가 가장 부드럽다.
```
