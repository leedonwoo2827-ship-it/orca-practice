# 공지 요청 메모 (7강 실습용 가상 자료)

> 가상의 교육 회사를 배경으로 지어낸 메모입니다. 실제 회사·인물·연락처와 관계없습니다.

- 보낸 사람: 경영지원팀 한지훈 매니저
- 받는 사람: 사내 공지 담당
- 요청: 전 직원 대상 사내 공지문 한 편. 사내 메신저와 게시판에 같은 글을 올림

## 공지할 내용
- 행사명: 연말 공유 폴더 정리 주간
- 기간: 2026년 12월 14일(월) ~ 12월 18일(금)
- 대상: 전 직원
- 이유: 공유 드라이브 용량이 90%를 넘어 새 자료 저장이 느려지고 있음
- 직원이 할 일
  1. 개인 폴더에서 1년 넘게 열지 않은 파일을 정리한다.
  2. 부서 공유 폴더의 지난 자료는 지우지 말고 각 부서 `_보관` 폴더로 옮긴다.
  3. 부서 공유 폴더에서 파일을 지울 때는 팀장 확인을 먼저 받는다.
  4. 개인정보가 들어 있는 파일은 직접 지우지 말고 정보보안 담당에게 문의한다.
- 정리 주간이 끝나면: 12월 21일(월)부터 용량을 많이 쓰는 폴더 목록을 부서별로 알려 줌
- 문의: 경영지원팀 한지훈 매니저, 내선 2047

## 요청 사항
- 딱딱하지 않게, 그러나 해야 할 일은 분명하게
- 메신저 한 화면에 들어올 정도의 길이
- 겁주는 표현(예: "삭제됩니다", "불이익") 쓰지 않기
