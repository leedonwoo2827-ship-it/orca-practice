# 5강 · 워크트리: 업무마다 독립된 책상

**Orca로 일하는 법** · 2. 업무 채팅 기본기

- 이번 강에서 할 수 있게 되는 것: 실습 저장소를 열고 업무별 워크트리를 만든다
- 실습 결과물: 첫 워크트리

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 결과를 영상 화면과 비교해 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `교육일정_원본.csv`
- `업무메모_이번주.md`

## 과제

내 업무 2개를 골라 워크트리를 각각 만들고 서로 다른 일을 맡긴 뒤, 한쪽 워크트리에서 다른 쪽 결과 파일이 보이는지 에이전트에게 물어 결과를 적으시오.

> 영상에서는 이 파일들을 `D:\orca-practice\01-업무채팅` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
업무메모_이번주.md를 읽고, 팀장님께 올릴 주간 보고 초안을 주간보고_초안.md 파일로 만들어 줘.
- 구성: 이번 주 한 일, 문제·이슈, 다음 주 할 일의 세 부분
- 한 화면 분량, 항목은 짧은 문장으로
- 메모에 "미정"인 내용은 미정 그대로 적고, 메모에 없는 내용은 지어내지 마
```

**메시지 2**

```text
교육일정_원본.csv를 날짜순 표로 정리해서 교육일정표_정리.md 파일로 만들어 줘.
- 열: 과정명, 시작일, 종료일, 방식, 정원, 비고
- 날짜는 2026-12-02 형식으로 맞춰 줘 (연도가 없으면 2026년으로 보고, 비고에 "연도 보정"이라고 적어 줘)
- 완전히 같은 행은 하나로 합쳐 줘
- 빈 칸이나 미정인 내용은 "확인 필요"로 표시해 줘
- 교육일정_원본.csv 원본은 고치지 마
```

**메시지 3**

```text
지금 이 폴더에 교육일정표_정리.md 파일이 있어? 주간보고_초안.md 파일은? 둘 다 있는지 없는지만 답해 주고, 지금 작업 중인 폴더 경로도 알려 줘. 파일은 고치지 마.
```

**메시지 4**

```text
지금 이 폴더에 주간보고_초안.md 파일이 있어? 있는지 없는지만 답해 줘.
```
