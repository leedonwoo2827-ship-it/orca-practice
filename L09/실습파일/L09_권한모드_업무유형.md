# 권한 모드와 업무 유형 (9강 실습용)

## 권한 모드 4가지 (Orca 안내서 기준, 화면 이름은 Orca 버전에 따라 다를 수 있음)
| 모드 (화면 표기) | 우리말 풀이 | 에이전트가 묻지 않고 하는 일 |
|---|---|---|
| Ask for approval | 승인 요청 | 거의 없음. 파일 쓰기·명령 실행 전에 묻는다 |
| Accept edits | 편집 허용 | 파일 고치기. 그 밖의 일(명령 실행 등)은 묻는다 |
| Approve for me | 자동 승인 | 승인 판단을 자동으로 맡긴다. 세부 동작은 에이전트마다 다르다 |
| Full access | 풀 액세스 | 모두. 묻지 않는다 (Orca 채팅 기본값) |

- 쓸 수 있는 모드는 에이전트마다 다르다. 승인 모드가 없는 에이전트는 항상 Full access로 동작한다.

## 업무 유형 8가지
1. 워크트리 안에서 회의록·공지문 초안 쓰고 고치기 (가상 또는 사내 일반 자료)
2. 처음 써 보는 지시문, 처음 써 보는 에이전트 시험하기
3. 파일 삭제·이동·폴더 정리
4. 메일 발송, 외부 사이트 등록처럼 밖으로 나가는 일
5. 여러 번 써서 검증된 반복 작업 (가상·공개 자료, 버려도 되는 워크트리)
6. 사내 제한 등급 자료(계약, 인사 평가) 다루기 — 3강의 예시 기준
7. 동료도 쓰도록 공개하는 봇
8. 개인정보·학습자 데이터 다루기 — 3강의 예시 기준으로 민감 등급
