## 받는 법

1. 이 페이지 위쪽의 초록색 **Code** 단추 → **Download ZIP** 을 누르고 압축을 풉니다.
2. 또는 Git 이 있다면: `git clone <이 저장소 주소>`

강 폴더의 `README.md` 에 그 강의 실습 파일 목록과, 영상에서 보낸 채팅 메시지가 그대로 들어 있습니다.
