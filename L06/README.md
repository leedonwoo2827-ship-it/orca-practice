# 6강 · 첫 업무 채팅: 회의록 정리

**Orca로 일하는 법** · 2. 업무 채팅 기본기

- 이번 강에서 할 수 있게 되는 것: 녹취 메모를 채팅으로 회의록과 할 일 목록으로 만든다
- 실습 결과물: 회의록·할 일 목록

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 결과를 영상 화면과 비교해 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `L06_녹취메모_운영점검회의.txt`
- `L06_지시문_회의록정리.md`
- `L06_회의록양식.md`

## 과제

최근 참석한 회의 1건의 메모로 회의록과 할 일 목록을 만들고, 원본 대조 질문으로 불일치를 찾아 고치시오. (이름·연락처·평가 내용은 지우고 입력)

> 영상에서는 이 파일들을 `D:\orca-practice\01-업무채팅` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
L06_녹취메모_운영점검회의.txt 를 읽고 회의록과 할 일 목록을 만들어 줘.

[만들 파일]
- 회의록_운영점검_1123.md : L06_회의록양식.md 의 제목과 순서를 그대로 따른다.
- 할일목록_운영점검_1123.md : 할 일, 담당자, 마감일, 상태 열이 있는 표 하나.

[지켜야 할 것]
- 잡담은 빼고, 업무 내용만 남긴다.
- 메모에 없는 내용은 지어내지 않는다. 마감일이 정해지지 않은 할 일은 마감일 칸에 "미정"이라고 적는다.
- 사람 이름과 날짜는 메모에 적힌 그대로 쓴다.
- 다 만들면 결정 사항, 보류 사항, 할 일 개수를 채팅으로 한 줄씩 알려 줘.
```

**메시지 2**

```text
할 일 목록을 담당자별로 묶어 줘.
```

**메시지 3**

```text
마감일이 미정인 할 일만 따로 보여 줘. 파일은 고치지 마.
```

**메시지 4**

```text
회의록과 할 일 목록을 L06_녹취메모_운영점검회의.txt 와 한 줄씩 대조해서, 메모에 없는 내용이나 날짜·이름이 다른 곳이 있으면 알려 줘. 고치지는 마.
```

**메시지 5**

```text
할일목록_운영점검_1123.md 를 바탕으로 참석자 네 명에게 보낼 회의 결과 메일 초안을 메일초안_운영점검_1123.md 로 만들어 줘. 제목, 인사말, 결정 사항 요약, 담당자별 할 일, 다음 회의 일정을 넣어 줘. 메일은 보내지 말고 파일로만 만들어.
```
