# 공지문 비교표 (L07 실습)

세 안을 `L07_공지문_비교기준.md` 의 다섯 기준으로 비교했다. 칸마다 ○(좋음) △(보통) ×(문제)와 한 줄 근거를 적었다.

| 기준 | A안 (notice-a) | B안 (notice-b) | C안 (notice-c) |
|---|---|---|---|
| 1. 사실 정확성 | ○ 기간·요일·문의처가 메모와 같고 없는 내용이 없다 | ○ 기간·요일·문의처가 메모와 같고 없는 내용이 없다 | × 메모에 없는 마감 시각을 넣었다 |
| 2. 할 일의 분명함 | ○ 할 일 네 가지가 빠짐없이 들어 있다 | ○ 할 일 네 가지가 번호 목록으로 분명하다 | ○ 할 일 네 가지를 표로 분명하게 정리했다 |
| 3. 길이 | △ 내용은 맞지만 한 화면에 비해 조금 길다 | ○ 600자 이내로 메신저 한 화면에 들어온다 | ○ 세 안 가운데 가장 짧다 |
| 4. 말투 | ○ 무난하고 겁주는 표현이 없다 | ○ 세 안 가운데 가장 부드럽고 겁주는 표현이 없다 | ○ 무난하고 겁주는 표현이 없다 |
| 5. 제목 | △ 무슨 공지인지는 알겠지만 평범하다 | ○ 질문형 제목이라 한눈에 들어온다 | ○ 무슨 공지인지 무난하게 드러난다 |
| **선택** | | **B안** | |

## 선택 이유
B안을 고른다. 사실이 정확하고, 세 안 가운데 말투가 가장 부드럽다.
