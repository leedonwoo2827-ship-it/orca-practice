# 8강 · 결과 검토: 디프·주석·저장

**Orca로 일하는 법** · 2. 업무 채팅 기본기

- 이번 강에서 할 수 있게 되는 것: 디프로 검토하고 줄 주석으로 수정 요청 후 커밋한다
- 실습 결과물: 수정 이력

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `L08_공지문_검토기준.md`
- `L08_공지문_예비초안.md`

## 예시 결과 (`예시결과/`, 2개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

6장에서 만든 회의록을 디프로 읽고 고칠 곳 두 군데에 주석을 달아 보내시오. 고치기 전과 후에 각각 저장 지점을 남기시오.

> 영상에서는 이 파일들을 `D:\orca-practice\01-업무채팅` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
(기간 줄) 기간 줄을 굵게 하고 인사 바로 다음으로 올려 주세요. 문구는 바꾸지 마세요.
```

**메시지 2**

```text
공지문 맨 위에 사내 메신저에 올릴 세 줄 요약을 넣어 줘. 기간, 할 일 핵심, 문의처가 한 줄씩 들어가게. 본문은 그대로 둬.
```

**메시지 3**

```text
이 워크트리의 저장 지점(커밋) 목록을 시간순으로 보여 줘. 저장 지점마다 무엇이 바뀌었는지 한 줄씩 우리말로 설명해 줘. 아무것도 고치지 마.
```

**메시지 4**

```text
세 줄 요약을 넣기 전 저장 지점으로 공지문을 되돌려 줘. 기록은 지우지 말고, 되돌린 것도 새 저장 지점으로 남겨 줘. 메시지는 "메신저용 요약 되돌리기 (게시판용)"로 해 줘.
```
