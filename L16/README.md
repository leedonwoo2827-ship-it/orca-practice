# 16강 · 제안서 한 절 쓰기와 근거 확인

**Orca로 일하는 법** · 4. 국제개발협력 사업 실무

- 이번 강에서 할 수 있게 되는 것: 요구사항 표로 제안서 한 절을 쓰고 근거를 대조한다
- 실습 결과물: 제안서 1개 절

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 예시 결과 (`예시결과/`, 3개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

같은 자료로 「수행 실적과 역량」 절 초안을 쓰고, 근거 확인표를 따로 만든 뒤 걸린 문장을 주석으로 고쳐 커밋하시오. (금액·실제 고객 정보 입력 금지)

> 영상에서는 이 파일들을 `D:\orca-practice\03-해외사업` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
L16_요구사항표_샘플.md 와 L16_회사실적요약.md 를 읽고, 제안서의 "Ⅱ. 사업 추진 전략" 절 초안을 써 줘.

[만들 파일]
- 파일 이름: 제안서_사업추진전략.md

[들어갈 내용]
1. 추진 목표 1문단 (3문장 이내)
2. 추진 전략 3개. 전략마다 제목, 설명 3~5문장, 대응하는 요구사항 ID
3. 단계별 추진 일정 표 (착수 / 개발 / 시범 운영 / 이관·종료). 월은 "착수 후 n개월"로 쓴다
4. 요구사항 R-01~R-10이 어느 전략에 반영됐는지 대응표

[지켜야 할 것]
- 사업이나 회사에 관한 사실을 말하는 문장은 끝에 근거 표시를 붙인다. 예: [R-02], [실적-1]
- 두 파일에 근거가 없는 사실은 쓰지 않는다. 꼭 필요하면 문장 대신 맨 끝 "확인 필요" 목록에 적는다
- "주의" 칸에 적힌 내용(아직 없는 기능, 납품 실적 없음)은 이미 있는 것처럼 쓰지 않는다
- 사업비, 입찰 가격, 인건비 같은 금액은 쓰지 않는다
- 문체는 제안서 문체("~하겠습니다" 대신 "~한다")로 쓴다
```

**메시지 2**

```text
제안서_사업추진전략.md 에서 사업이나 회사에 관한 사실을 말하는 문장을 모두 뽑아서, 원문과 하나씩 대조한 근거확인표_사업추진전략.md 를 만들어 줘.

- 열: 번호, 문장(앞 30자), 붙은 근거 표시, 원문에서 찾은 내용, 판정, 고칠 방법
- 판정은 "일치 / 부분 일치 / 근거 없음" 셋 중 하나
- 대조할 원문은 L16_요구사항표_샘플.md 와 L16_회사실적요약.md 두 파일뿐이다. 네 상식으로 맞다고 판정하지 마

- 제안서_사업추진전략.md 본문은 절대 고치지 마
```
