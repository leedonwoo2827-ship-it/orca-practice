# 지시문: 제안서 한 절 초안 (16강 시연용, 복사해서 에이전트 입력창에 붙여 넣기)

L16_요구사항표_샘플.md 와 L16_회사실적요약.md 를 읽고, 제안서의 "Ⅱ. 사업 추진 전략" 절 초안을 써 줘.

[만들 파일]
- 파일 이름: 제안서_사업추진전략.md

[들어갈 내용]
1. 추진 목표 1문단 (3문장 이내)
2. 추진 전략 3개. 전략마다 제목, 설명 3~5문장, 대응하는 요구사항 ID
3. 단계별 추진 일정 표 (착수 / 개발 / 시범 운영 / 이관·종료). 월은 "착수 후 n개월"로 쓴다
4. 요구사항 R-01~R-10이 어느 전략에 반영됐는지 대응표

[지켜야 할 것]
- 사업이나 회사에 관한 사실을 말하는 문장은 끝에 근거 표시를 붙인다. 예: [R-02], [실적-1]
- 두 파일에 근거가 없는 사실은 쓰지 않는다. 꼭 필요하면 문장 대신 맨 끝 "확인 필요" 목록에 적는다
- "주의" 칸에 적힌 내용(아직 없는 기능, 납품 실적 없음)은 이미 있는 것처럼 쓰지 않는다
- 사업비, 입찰 가격, 인건비 같은 금액은 쓰지 않는다
- 문체는 제안서 문체("~하겠습니다" 대신 "~한다")로 쓴다
