# 제안서 근거 확인 체크리스트 (16강 시연·실습용)

- [ ] 사실을 말하는 문장마다 근거 표시([R-..], [실적-..], [역량-..])가 붙어 있는가
- [ ] 근거 표시가 가리키는 원문에 실제로 그 내용이 있는가 (숫자·연도·국가 이름까지)
- [ ] 원문보다 부풀린 표현이 없는가 (예: "시범 개발 중" → "보유", "2개 언어" → "다국어 완벽 지원")
- [ ] "주의" 칸의 내용(말레카어 화면 없음, 오프라인 앱 납품 실적 없음)을 이미 있는 것처럼 쓰지 않았는가
- [ ] 요구사항 R-01~R-10이 빠짐없이 대응표에 있는가
- [ ] 사업비·입찰 가격·인건비 같은 금액이 없는가 (데이터 등급 '사내 제한')
- [ ] 자료로 확정할 수 없는 내용이 "확인 필요" 목록에 모여 있는가
