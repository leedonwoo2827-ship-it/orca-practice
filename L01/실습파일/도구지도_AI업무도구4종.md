# AI 업무 도구 지도 (1강 실습용)

> 이 파일은 강의용 일반 정리입니다. 특정 회사의 시스템을 설명하지 않습니다. 도구 이름은 대표 예시이며, 실제로 어떤 도구를 쓸 수 있는지는 각 회사의 규정과 계약을 따릅니다.

## 1. 네 가지 도구 유형

| 유형 | 대표 예 | 일하는 곳 | 잘하는 일 | 약한 점 |
|---|---|---|---|---|
| 채팅형 AI | 웹·앱의 AI 채팅 서비스 | 대화창 하나 | 질문 답하기, 짧은 초안, 아이디어 | 내 폴더의 파일을 직접 고치거나 여러 파일을 한꺼번에 다루기 어렵다 |
| 브라우저 AI | AI 기능이 들어간 웹 브라우저 | 지금 열어 둔 웹 페이지 | 로그인된 웹 화면 요약, 양식 입력, 조회 | 웹 화면 밖의 파일 작업에는 맞지 않다 |
| 에이전트 IDE | Orca | 내 PC의 작업 폴더(git 저장소) | 파일을 읽고 쓰는 업무, 여러 작업을 나란히, 바뀐 부분(디프) 검토 | 결과 파일과 바뀐 부분을 사람이 읽고 판단해야 한다 (노코드 도구가 아님) |
| 봇 | Orca Bots | 봇이 사는 폴더 + 팀 메신저·일정 | 정해진 반복 업무, 동료의 요청 받기, 정기 실행 | 봇을 만든 사람의 권한으로 동작하므로 공개 범위를 조심해야 한다 |

## 2. 같은 일을 어디서 할까 (예시)

| 업무 | 알맞은 유형 | 이유 |
|---|---|---|
| 용어 하나의 뜻을 빨리 묻기 | 채팅형 AI | 파일이 필요 없는 한 번의 질문 |
| 로그인해야 보이는 사내 웹 화면에서 목록 옮기기 | 브라우저 AI | 일이 웹 화면 안에서 끝난다 |
| 회의 메모 3개를 읽고 회의록·할 일 목록 파일 만들기 | 에이전트 IDE (Orca) | 여러 파일을 읽고 새 파일을 만들고, 결과를 검토해야 한다 |
| 매주 월요일 팀 현황 보고 초안 만들기 | 봇 | 같은 요청이 정기적으로 반복된다 |

## 3. Orca가 하는 일 (orca.dev 문서 기준)

- 업무마다 **워크트리**(작업용 독립 폴더)를 따로 만든다. 마음에 안 들면 그 워크트리만 버린다. (5강)
- Claude Code, Codex 같은 **에이전트**를 채팅 화면이나 터미널로 쓴다. (4·6강)
- 같은 일을 여러 에이전트에게 동시에 맡기고 결과를 골라 쓸 수 있다. (7강)
- **디프**(바뀐 부분 비교 화면)에서 결과를 검토하고, 줄에 메모를 달아 에이전트에게 돌려보낸다. (8강)
- 잘 되는 일은 **봇**으로 만들어 팀 메신저나 일정에 연결한다. (14·18·19강)

## 4. 사람이 맡는 일

- 무엇을 맡길지 정하기 (요청문 쓰기, 2강)
- 어떤 자료를 넣어도 되는지 판단하기 (데이터 등급, 3강)
- 결과를 읽고 맞는지 확인하고 저장하기 (8강)
- 외부 발송·결제·인사 같은 최종 결정
