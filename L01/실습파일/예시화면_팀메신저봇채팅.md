# 팀 메신저 봇 채팅 — 예시 화면 (글로 그린 시안)

> 가상의 교육 회사 "새솔에듀"의 예시입니다. 회사 이름, 사람, 봇, 대화는 모두 지어낸 것입니다. Orca Bots는 커넥터로 Slack 같은 팀 도구와 연결할 수 있습니다. 실제 연결 방법은 14·19강에서 다룹니다.

## 화면 뒤에서 일어나는 일 (일반 흐름)

1. 동료가 메신저의 봇 대화방에 요청을 보낸다.
2. 봇을 만든 사람의 PC에 있는 Orca가 요청을 받는다. 그 PC가 켜져 있고 온라인이어야 한다.
3. 봇이 자기 폴더에서 에이전트(예: Claude Code)로 일을 처리하고 결과 파일을 만든다.
4. 결과가 같은 대화방으로 돌아온다.

## 지금 Orca 업무 채팅과 같은 점, 다른 점

| 구분 | Orca 업무 채팅 (이 과정 2~13강) | 팀 메신저 봇 채팅 (14강 이후) |
|---|---|---|
| 대화 장소 | 내 PC의 Orca | 팀 메신저 대화방 |
| 대화 상대 | 에이전트 (Claude Code) | 내가 만든 봇 |
| 요청 방식 | 채팅으로 요청 → 결과 파일 확인 | 같음 |
| 누가 쓰나 | 나 | 나 + 허락한 동료 |
| 주의할 점 | 결과 검토 | 결과 검토 + 동료가 내 권한으로 봇을 쓴다는 점 |
