# 1강 · AI 에이전트로 일하는 법: Orca는 어디에 쓰나

**Orca로 일하는 법** · 1. 왜 Orca인가

- 이번 강에서 할 수 있게 되는 것: 채팅형 AI·브라우저 AI·에이전트 IDE·봇의 쓰임을 구분한다
- 실습 결과물: 도구 지도

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `도구지도_AI업무도구4종.md`
- `예시화면_팀메신저봇채팅.md`

## 예시 결과 (`예시결과/`, 1개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

내가 주 1회 이상 하는 업무 3개를 적고, 각각 4유형 중 어디에 알맞은지 이유를 한 줄씩 붙이시오.

> 영상에서는 이 파일들을 `D:\orca-practice\00-시작` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
도구지도_AI업무도구4종.md 파일을 읽고, 처음 보는 동료에게 설명하듯 다섯 줄로 요약해 줘. 파일은 고치지 마.
```

**메시지 2**

```text
도구지도_AI업무도구4종.md를 기준으로, 아래 업무 다섯 개에 각각 어떤 도구 유형이 알맞은지 표로 알려 줘. 열은 업무, 알맞은 유형, 이유(한 줄).
1. 회의에서 나온 낯선 용어 하나의 뜻을 빨리 알고 싶다
2. 로그인해야 보이는 사내 웹 화면에서 신청자 목록을 표로 옮기고 싶다
3. 회의 메모 파일 3개를 읽고 회의록과 할 일 목록 파일을 만들고 싶다
4. 매주 월요일 아침 팀 현황 보고 초안을 받고 싶다
5. 거래처에 견적서를 메일로 보내고 싶다
사람이 결정해야 하는 일이 있으면 그렇다고 적어 줘.
```

**메시지 3**

```text
방금 만든 표를 도구지도_읽기노트.md 파일로 저장해 줘.
- 표 아래에 "Orca를 쓰기 좋은 일의 특징"을 세 줄로 적어 줘
- 도구지도_AI업무도구4종.md에 없는 내용은 넣지 마
```
