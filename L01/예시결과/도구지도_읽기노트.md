# 도구지도 읽기 노트

> 출처: 도구지도_AI업무도구4종.md (1강 실습용). 아래 내용은 그 파일에 적힌 범위 안에서만 정리했습니다.

## 업무별 알맞은 도구 유형

| 업무 | 알맞은 유형 | 이유 |
|---|---|---|
| 1. 낯선 용어 하나의 뜻을 빨리 알고 싶다 | 채팅형 AI | 파일이 필요 없는 한 번의 질문이라 대화창에서 끝난다 |
| 2. 로그인해야 보이는 사내 웹 화면의 신청자 목록을 표로 옮기고 싶다 | 브라우저 AI | 일이 지금 열어 둔 로그인된 웹 화면 안에서 끝난다 |
| 3. 회의 메모 3개를 읽고 회의록·할 일 목록 파일 만들기 | 에이전트 IDE (Orca) | 여러 파일을 읽고 새 파일을 만든 뒤 디프로 검토해야 한다 |
| 4. 매주 월요일 아침 팀 현황 보고 초안 | 봇 | 같은 요청이 정기적으로 반복되고 일정에 연결할 수 있다 |
| 5. 거래처에 견적서를 메일로 보내기 | **도구가 아니라 사람** (초안까지만 도구) | 외부 발송은 사람이 맡는 최종 결정이다 |

5번 보충: 견적서 초안을 만드는 데까지는 도구를 쓸 수 있지만, 외부 발송은 사람의 최종 결정에 속한다. 봇은 봇을 만든 사람의 권한으로 동작하므로 공개 범위를 조심해야 한다.

## Orca를 쓰기 좋은 일의 특징

- 내 PC의 작업 폴더(git 저장소) 안에서 파일을 읽고 쓰는 일이다.
- 여러 파일을 다루거나, 같은 일을 여러 에이전트에게 동시에 맡기고 결과를 골라 쓸 수 있는 일이다.
- 바뀐 부분(디프)을 사람이 읽고 판단해야 하는 일이다. 업무마다 워크트리를 따로 만들어, 마음에 안 들면 그 워크트리만 버릴 수 있다.
