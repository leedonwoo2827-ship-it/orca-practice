## 3. 실습 파일과 데이터 점검

| 점검 항목 | 결과 |
|---|---|
| 실습 파일 답 셀 44칸이 모두 비어 있는가 | 예 (빈 칸 44/44) |
| 답 셀 배경이 연노랑(FFF2CC)인가 | 예 (44/44) |
| 두 파일의 `A1:F15`·`L1:M6` 데이터가 같은가 | 예 (불일치 0건) |
| 정답 파일 데이터가 CSV 원본과 같은가 | 예 (불일치 0건) |
| 숫자 열 `D`·`E`·`F`가 숫자로 들어갔는가 | 예 (문자 0칸) |
| 시트 구성 | 실습 ['강좌운영', '문제'] / 정답 ['강좌운영', '문제'] |


### 표시 형식

| 셀 | 표시 형식 | 비고 |
|---|---|---|
| `D2:D15` | `0` | 수강인원, 정수 |
| `E2:E15` | `0.0` | 만족도, 소수 한 자리 |
| `F2:F15` | `0` | 완료율, 정수 |
| `L12` | `0.00` | 5번 답, 소수 두 자리 |

`E10`(협업 도구 활용법, 만족도 4.0)은 파일 안에 정수 `4`로 저장됩니다. openpyxl이 `4.0`을 `4`로 기록하기 때문이며, 표시 형식 `0.0`이 걸려 있어 엑셀에서는 `4.0`으로 보이고 계산 결과도 같습니다.

## 4. 짚어 둘 점 — 5번 `L12`의 반올림 경계

IT 강좌 4건의 만족도 평균은 **4.375**로, 소수 셋째 자리가 정확히 5인 반올림 경계값입니다. 경계값은 2진 부동소수 오차로 결과가 흔들릴 수 있어 따로 확인했습니다.

| 확인 항목 | 결과 |
|---|---|
| `4.6+4.8+4.1+4.0`을 2진 부동소수로 더한 합 | `17.5` (오차 없음) |
| 평균 | `4.375` — 2진수로 정확히 표현되는 값 |
| 십진수(Decimal) 경로의 `ROUND(...,2)` | **4.38** |
| 2진 부동소수 경로의 `ROUND(...,2)` | **4.38** |

`4.6`·`4.8`·`4.1`은 각각 2진수로 정확히 표현되지 않지만 더하는 과정에서 오차가 상쇄되어 합이 정확히 `17.5`가 되고, 평균 `4.375`도 2진수로 딱 떨어지는 값입니다. 두 계산 경로가 같은 값을 내므로 엑셀에서도 `4.38`로 계산됩니다.

수업에서 짚을 점은 부동소수가 아니라 **셀 서식과 `ROUND`의 차이**입니다. `ROUND` 없이 셀 서식만 소수 두 자리로 바꾸면 보이는 값은 `4.38`지만 셀에 든 값은 `4.375` 그대로라, 그 셀을 다시 계산에 쓰면 결과가 달라집니다.

## 5. 짚어 둘 점 — 1번 문항 `OR` 둘째 조건의 변별력

1번 조건의 `OR` 둘째 항목(`완료율 85 이상`)은 이 데이터에서 등급을 바꾸는 행이 **0개**입니다.

| 완료율 85 이상인 행 | 등급 | 그 등급이 된 까닭 |
|---|---|---|
| 2행 (완료율 85) | 핵심 | `AND` 통과 (수강인원 120, 완료율 85) |
| 4행 (완료율 91) | 성장 | 만족도 4.8로 `OR` 첫째 항목도 통과 |
| 8행 (완료율 88) | 핵심 | `AND` 통과 (수강인원 300, 완료율 88) |
| 15행 (완료율 90) | 핵심 | `AND` 통과 (수강인원 150, 완료율 90) |

즉 수강생이 `OR(E2>=4.5,F2>=85)`에서 `F2>=85`를 빼고 `E2>=4.5`만 써도 14행의 결과가 모두 같게 나옵니다. 조건을 하나 빠뜨린 수식을 결과로는 걸러낼 수 없습니다.

고칠 방법은 세 가지입니다.

1. **기준을 낮춘다.** 완료율 85 → 75로 바꾸면 6, 13행이 완료율 조건만으로 `성장`이 되어 변별력이 생깁니다. 문항 문장·정답 수식·정답 결과값을 함께 고쳐야 합니다.
2. **데이터를 바꾼다.** 한 행의 만족도를 4.5 미만으로 낮추고 완료율을 85 이상으로 올립니다. CSV를 고친 뒤 `make_xlsx_02.py`를 다시 실행해야 합니다.
3. **그대로 둔다.** 조건을 빠뜨려도 답이 같아 보이는 사례로 수업에서 설명합니다. 대본의 "수식에 오류가 없다고 답이 맞는 것은 아니다"와 이어집니다.

어느 쪽이든 채점 정답은 바뀌지 않으므로 지금 파일을 그대로 써도 문제는 없습니다.
