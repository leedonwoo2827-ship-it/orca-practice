# 지시문: 실습 문제와 엑셀 파일 (12강 시연용, 단계별로 복사해서 입력창에 붙여 넣기)

## 지시문 1 — 문항 집필

강의계획서_컴활1급실기엑셀.md의 2차시(계산작업, 함수 중첩)와 대본_02_함수중첩.md를 읽고, 이 차시의 실습 문제를 써 줘.

[자료]
- 데이터: 실습데이터_강좌운영.csv (14행), 실습데이터_분류표.csv (5행). 둘 다 가상 자료다.
- 형식: 문항형식_예시.json의 구조를 그대로 따른다.

[만들 파일]
- 문항_02_함수중첩.json : 문항 데이터
- 문항_02_함수중첩.md : 사람이 읽는 문제지 (문제 번호, 지시문, 답을 넣을 셀, 조건)

[문항 조건]
- 5문항. 대본의 예제 2개(평가 등급, 분류명 찾기)와 같은 유형 2개 + 새 유형 3개(LEFT·MID·CHOOSE 조합, INDEX·MATCH, ROUND와 AVERAGEIF 조합 중에서).
- 문항마다 답을 넣을 셀 범위, 정답 수식, 쓰는 함수, 난이도(하·중·상)를 적는다.
- 문제 문장과 표는 모두 새로 쓴다. 기출문제 원문을 인용하거나 흉내 내지 않는다. 각 문항에 "출처": "자사 재집필"을 적는다.
- 데이터 범위: 강좌운영 표는 A1:F15(머리글 1행), 분류표는 L1:M6에 둔다고 가정한다. 답 셀은 G열부터, 단일 값은 L9 아래에 둔다.

## 지시문 2 — 실습·정답 엑셀 파일 생성

문항_02_함수중첩.json을 바탕으로 파이썬 openpyxl로 엑셀 파일 두 개를 만들어 줘. openpyxl이 없으면 설치해도 돼.

[만들 파일]
- make_xlsx_02.py : 파일을 만드는 스크립트 (다시 실행할 수 있게)
- 실습_02_함수중첩.xlsx : 데이터와 문제 안내만 있고, 답 셀은 비워 둔다. 답 셀에 연한 노란색 배경.
- 정답_02_함수중첩.xlsx : 실습 파일과 같은 구조에 답 셀마다 정답 **수식**을 넣는다 (값이 아니라 수식).

[시트 구성]
- 시트1 "강좌운영": A1:F15 데이터, L1:M6 분류표, 답 셀
- 시트2 "문제": 문항 번호, 문제 문장, 답 셀 범위
- 숫자 열은 숫자 형식으로 넣는다 (문자로 넣지 않는다).

## 지시문 3 — 자동 점검

정답_02_함수중첩.xlsx를 다시 열어서 점검해 줘.
1. 답 셀마다 들어 있는 수식을 "문항 / 셀 / 수식" 표로 보여 줘.
2. 같은 계산을 파이썬으로 따로 해서, 셀마다 기대값을 표로 보여 줘. (openpyxl은 수식 결과를 계산하지 않으니 엑셀에서 열기 전에는 값이 비어 있는 게 정상이다.)
3. 실습 파일의 답 셀이 모두 비어 있는지, 두 파일의 데이터가 같은지 확인해 줘.
4. 결과를 검증결과_02.md로 저장해 줘. 맨 끝에 "엑셀에서 직접 확인할 셀" 목록을 적어 줘.
