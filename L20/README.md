1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.

4. `과제.md` 를 내 업무로 해 봅니다.

## 과제

우리 팀의 반복 업무 메모(5건 이상)를 만들고, 6가지 질문으로 분류한 뒤 봇 후보 1개의 레시피 제안서를 쓰시오. 자가 검토 체크리스트를 통과시키고, 샘플 자료로 지시문을 시험한 결과를 붙여 팀과 공유한다. (실제 개인정보·금액 입력 금지)

> 영상에서는 이 파일들을 `D:\orca-practice\04-확산` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
L20_업무후보메모.md 의 업무 T1~T5를 L20_봇후보_6질문.md 의 질문 1~6에 차례로 답해서 분류하고, 업무분류_교육운영팀.md 로 저장해 줘.

- 표 열: 업무ID, 업무, 질문1~6 답(예/아니오), 판정(봇으로 만든다 / 채팅으로 한다 / 사람이 한다), 근거
- 답마다 메모의 빈도·하는 사람·입력 자료·메모 칸을 근거로 든다
- 메모에 없는 내용은 추측하지 말고 맨 끝 "확인 필요"에 적는다
- 표 아래에 봇 후보 중 먼저 시작할 업무 1개를 추천하고 이유를 2줄로 쓴다
```

**메시지 2**

```text
T1 과정 개강 안내문 작성 업무로 L20_레시피제안서_양식.md 의 9칸을 모두 채워서 레시피제안서_개강안내봇.md 로 저장해 줘.

- 입력 자료는 L20_개강정보_샘플.csv 형식의 개강 정보 표다
- 4. 지시문 초안은 [할 일]과 [지켜야 할 것]으로 나누고, 지켜야 할 것에 지어내기 금지, 수강생 개인정보 금지, 금액 금지, 외부 발송 금지(게시·발송은 운영 담당), 파일 삭제 금지를 넣는다
- 6. 안전은 L19_공개체크리스트_양식.md 기준(공개 범위는 운영 담당 3명, 권한 모드는 Full access보다 낮게)으로 쓴다. 그 파일이 없으면 괄호 안 기준만 쓴다
- 데이터 등급은 업무 메모만으로 확정할 수 없으면 "확인 필요"로 남긴다
- 업무 메모에 없는 숫자는 지어내지 않는다
```

**메시지 3**

```text

```
