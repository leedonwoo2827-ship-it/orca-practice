# 봇 후보를 고르는 6가지 질문 (20강 실습용)

> 업무 하나를 놓고 위에서부터 차례로 답한다. 마지막 판정은 "봇으로 만든다 / 채팅으로 한다 / 사람이 한다" 중 하나.

| 번호 | 질문 | "아니오"라면 |
|---|---|---|
| 1 | 자주 반복되는가? (주 1회 이상) | 봇보다 그때그때 채팅이 낫다 |
| 2 | 여러 사람이 하거나, 결과를 여러 사람이 쓰는가? (2인 이상) | 나만 쓰는 개인 봇이나 채팅으로 충분하다 |
| 3 | 입력 자료가 파일이나 표로 정해져 있는가? | 먼저 자료 모으는 방식부터 정한다 |
| 4 | 결과물의 형식이 정해져 있는가? (양식, 파일 이름) | 먼저 양식부터 만든다 |
| 5 | 다루는 자료가 팀 공개 봇에 허용되는 데이터 등급인가? | 그 자료를 빼고 설계하거나, 봇으로 만들지 않는다 |
| 6 | 판단·승인·외부 발송·결제·인사가 걸리는가? ("예"라면) | 그 부분은 사람이 한다. 봇은 초안까지만 쓴다 |

- 1~5가 모두 "예"이고 6의 사람 몫이 분명하면 → **봇 후보**
- 1이나 2가 "아니오"면 → **채팅으로 한다**
- 5가 "아니오"인데 자료를 뺄 수 없거나, 일의 핵심이 6이면 → **사람이 한다**
