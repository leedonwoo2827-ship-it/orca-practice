# 레시피 제안서 자가 검토 체크리스트 (20강 실습용)

- [ ] 6가지 질문에 모두 답했고, 답마다 근거(업무 메모의 빈도·인원·자료)가 있는가
- [ ] 입력 자료를 누가 언제 채우는지 적혀 있는가
- [ ] 출력물의 양식과 파일 이름 규칙이 정해져 있는가
- [ ] 지시문에 [지켜야 할 것]이 있고, 지어내기·개인정보·금액·외부 발송·삭제를 막는가
- [ ] 데이터 등급이 자료별로 적혀 있고, 팀 공개 봇 허용 범위 안인가
- [ ] 공개 범위와 권한 모드가 19강 공개 체크리스트 기준에 맞는가
- [ ] 사람이 하는 일(판단·승인·발송)이 분명히 나뉘어 있는가
- [ ] 성공 기준이 4주 안에 실제로 잴 수 있는 숫자인가
- [ ] 업무 메모에 없는 사실(인원, 빈도, 시간)을 지어내지 않았는가 ("확인 필요"로 남겼는가)
