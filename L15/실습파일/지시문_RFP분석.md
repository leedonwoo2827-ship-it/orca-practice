# 지시문: 제안요청서 분석 (15강 시연용, 단계별로 복사해서 입력창에 붙여 넣기)

## 지시문 1 — 요구사항·평가기준·일정 표

공고문_누리아교원디지털역량.md를 읽고 RFP분석_양식.md의 형식대로 분석표를 만들어 줘.

[만들 파일]
- RFP분석_누리아교원.md

[규칙]
- 모든 행에 근거 쪽 번호를 적는다. 쪽 번호는 문서 안의 "— n쪽 —" 표시를 기준으로 한다.
- 요구사항은 ID가 붙은 것을 하나도 빠뜨리지 않는다. ID가 없는데 요구사항처럼 읽히는 문장(제안서 작성 지침 등)도 "ID 없음"으로 넣는다.
- 원문에 없는 내용은 쓰지 않는다. 해석이 필요한 곳은 "모호" 칸에 표시만 하고 내 판단을 덧붙이지 않는다.
- 끝나면 요구사항 개수, 평가 항목 배점 합계, 일정 개수를 알려 줘.

## 지시문 2 — 모호한 요구사항 질의 목록

RFP분석_누리아교원.md에서 "모호"로 표시한 요구사항으로 발주 기관에 보낼 질의 목록 초안을 만들어 줘.

[만들 파일]
- 질의목록_누리아교원.md

[형식]
- 표: 번호 / 관련 ID·쪽 / 모호한 표현(원문 그대로 인용) / 질의 문장 / 왜 중요한가(제안서 어느 부분에 영향) / 우선순위(상·중·하)
- 질의 문장은 예·아니오나 숫자로 답할 수 있게, 공손한 공문 말투로 쓴다.
- 우선순위 "상"은 평가 배점이나 사업 범위(인원·기간·비용)에 영향을 주는 것.
- 맨 위에 질의 접수 마감 일시를 공고문에서 찾아 적는다.

## 지시문 3 — 교차 확인

공고문_누리아교원디지털역량.md 안에서 같은 대상을 가리키는데 숫자나 내용이 서로 다른 곳을 모두 찾아 줘.
- 표: 대상 / 위치 1(쪽·절, 원문 인용) / 위치 2(쪽·절, 원문 인용) / 차이 / 제안서에 미치는 영향
- 사업 기간은 날짜로 직접 계산해서 개월 수를 비교해 줘.
- 평가 배점은 합계를 다시 더해서 확인해 줘.
- 찾은 항목 중 질의목록_누리아교원.md에 없는 것은 질의로 추가해 줘.
- RFP분석_누리아교원.md 맨 끝에 "교차 확인 결과" 절로 붙여 줘.
