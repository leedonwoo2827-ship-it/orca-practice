# [가상 실습 자료] 제안요청서

> 이 문서는 강의 실습을 위해 만든 **가상의 공고문**입니다. 발주 기관, 협력국, 사업, 숫자는 모두 지어낸 것이며 실제 기관·사업과 관계가 없습니다. 분석 연습을 위해 일부러 모호한 표현과 서로 맞지 않는 숫자를 넣었습니다.

**사업명**: 누리아 공화국 초·중등 교원 디지털 역량 강화 이러닝 사업
**발주 기관**: 국제개발협력진흥원(가상)
**공고 번호**: 가상-2027-0115
**공고일**: 2027년 1월 15일

— 1쪽 —

## 1. 사업 개요

### 1.1 배경
누리아 공화국(가상) 교육부는 「국가 교육 디지털 전환 계획 2026~2030」에 따라 모든 초·중등 교원의 디지털 수업 역량을 높이려 한다. 그러나 수도권 밖 지역은 인터넷 속도가 느리고 연수 기관이 부족해, 교원 대상 집합 연수만으로는 목표를 달성하기 어렵다. 이에 국제개발협력진흥원(가상)은 누리아 교육부와 협력하여 교원용 이러닝 과정과 학습관리시스템을 구축하고 운영 역량을 이전하는 사업을 추진한다.

### 1.2 사업 목표
1. 교원 디지털 역량 이러닝 과정 개발 및 운영
2. 현지 여건에 맞는 학습관리시스템(LMS) 구축
3. 누리아 교육부 연수 담당 인력의 운영 역량 강화
4. 사업 종료 후 현지 기관의 자립 운영 기반 마련

### 1.3 사업 개요
| 항목 | 내용 |
|---|---|
| 사업 기간 | 계약 체결일로부터 **18개월** |
| 사업 대상 | 누리아 공화국 3개 시범 주(州)의 초·중등 교원 **3,000명** 이상, 교육부 연수 담당자 30명 |
| 사업 예산 | 별도 공지 (가상 실습 자료에서는 생략) |
| 계약 방법 | 협상에 의한 계약 |

## 3. 세부 요구사항

### 3.1 콘텐츠 요구사항
| ID | 요구사항 |
|---|---|
| CON-01 | 기본 과정 10차시, 심화 과정 10차시 이상을 개발한다. 차시당 학습 시간은 25분 내외로 한다. |
| CON-02 | 콘텐츠는 영어와 현지어로 제공하며, **필요 시** 주요 교과별 사례를 포함한다. |
| CON-03 | 모든 동영상에는 자막을 제공한다. |
| CON-04 | 현지 교육과정과의 정합성을 누리아 교육부와 협의하여 확보한다. |
| CON-05 | 개발 콘텐츠의 저작권은 발주 기관과 누리아 교육부가 공동으로 가진다. |

### 3.2 시스템 요구사항
| ID | 요구사항 |
|---|---|
| SYS-01 | 학습관리시스템은 **현지 인터넷 여건을 고려한 저대역폭 환경**에서 원활히 동작해야 한다. |
| SYS-02 | 인터넷이 연결되지 않은 환경에서도 학습할 수 있도록 **적정 수준의 오프라인 학습**을 지원한다. |
| SYS-03 | 안드로이드 스마트폰에서 학습할 수 있어야 한다. |
| SYS-04 | 학습 이력·평가 결과를 누리아 교육부가 내려받을 수 있어야 한다. |
| SYS-05 | 개인정보는 누리아 공화국 법령에 따라 처리하고, 서버 위치는 발주 기관과 협의한다. |

### 3.3 운영 요구사항
| ID | 요구사항 |
|---|---|
| OPR-01 | 시범 운영(1개 주, 교원 300명)을 거친 뒤 본 운영을 시작한다. |
| OPR-02 | 학습자 문의에 대응하는 현지 학습 지원 창구를 운영한다. 응답 기준은 **신속하게** 한다. |
| OPR-03 | 수료 기준은 진도율 80% 이상, 평가 점수 60점 이상으로 한다. |
| OPR-04 | 연수 담당자 30명에게 운영자 연수를 실시하고, 그중 **일부**를 한국 초청 연수에 참여시킨다. |

| EVA-02 | 성과 지표는 수료율, 디지털 역량 진단 점수 변화, 수업 적용 사례 수로 한다. 목표값은 착수 보고 때 협의한다. |
| EVA-03 | 분기마다 진도 보고서를, 종료 시 최종 보고서를 제출한다. |

### 3.5 사업 관리 요구사항
| ID | 요구사항 |
|---|---|
| MNG-01 | 사업 책임자는 유사 사업 수행 경력이 있어야 하며, 사업 기간 중 **현지에 상주**하는 인력을 1명 이상 둔다. |
| MNG-02 | 착수·중간·종료 보고회를 누리아 교육부와 함께 개최한다. |

## 4. 제안서 작성 지침
1. 제안서는 한국어로 작성하고, 요약문(5쪽 이내)은 영어로 함께 제출한다.
2. 본문은 50쪽 이내로 한다(표지·목차·붙임 제외).
3. 과업 범위의 6개 과업별로 수행 방법과 산출물을 제시한다.
4. 교원 **2,500명**에 대한 운영 계획(시범 운영 포함)을 구체적으로 제시한다.
5. 저대역폭·오프라인 학습 지원 방안은 기술적 근거와 함께 제시한다.
6. 협력국 정부 인사 등에게 금품·향응을 제공하지 않겠다는 청렴 서약서를 붙임으로 제출한다.

## 5. 평가 기준

### 5.1 평가 방법
- 기술 평가 80점 + 가격 평가 20점 = 100점
- 기술 평가 점수가 기술 평가 배점의 85% 미만이면 협상 적격자에서 제외한다.
- 기술 평가는 서면 평가와 발표 평가로 한다.

### 5.2 기술 평가 항목
| 평가 부문 | 평가 항목 | 배점 |
|---|---|---|
| 사업 이해 | 사업 배경·목표 이해도, 협력국 여건 분석 | 10 |
| 수행 방법 | 과정 개발 방법론과 콘텐츠 품질 관리 | 20 |
| 수행 방법 | 플랫폼 구축 방안 (저대역폭·오프라인) | 15 |
| 수행 방법 | 운영·학습 지원 방안 | 10 |
| 성과 관리 | 성과 지표와 측정 방법, 자립 운영 방안 | 10 |
| 사업 관리 | 수행 조직·인력, 일정·위험 관리 | 10 |
| 수행 실적 | 유사 사업 수행 실적 | 5 |
