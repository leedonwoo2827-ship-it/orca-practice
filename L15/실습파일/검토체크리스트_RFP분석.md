# 제안요청서 분석 검토 체크리스트

- [ ] 공고문의 ID 있는 요구사항이 모두 표에 있는가 (개수 대조)
- [ ] 모든 행에 근거 쪽 번호가 있는가
- [ ] 무작위로 고른 3행을 공고문 해당 쪽에서 직접 대조했는가 ← **사람이 직접 확인**
- [ ] 평가 항목 배점 합계가 공고문의 기술 평가 배점과 같은가
- [ ] 일정 표에 질의 마감과 제안서 제출 마감이 시각까지 있는가
- [ ] 원문에 없는 내용(추측, 회사 전략)이 섞이지 않았는가
- [ ] 모호한 요구사항마다 질의가 있고, 질의 문장이 예·아니오나 숫자로 답할 수 있는가
- [ ] 서로 맞지 않는 숫자(인원·기간·배점)를 찾아 질의에 반영했는가
- [ ] 질의는 접수 마감 전에 보낼 수 있도록 일정에 표시했는가
