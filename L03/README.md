# 3강 · 데이터 등급과 도구 선택 (예시 기준)

**Orca로 일하는 법** · 1. 왜 Orca인가

- 이번 강에서 할 수 있게 되는 것: 업무를 예시 데이터 등급과 도구 선택 순서에 따라 분류한다
- 실습 결과물: 내 업무 분류표

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `업무목록_샘플.csv`
- `예시기준_데이터등급.md`
- `예시기준_도구선택6단계.md`

## 예시 결과 (`예시결과/`, 3개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

`내업무분류표_양식.md`에 내 업무 10개를 적고 등급·멈춘 단계·도구를 분류한 뒤, 소속 회사의 정보보안 규정과 대조해 다른 점을 적으시오. (업무 설명만 적고 실제 자료는 넣지 않는다)

> 영상에서는 이 파일들을 `D:\orca-practice\00-시작` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
예시기준_데이터등급.md와 예시기준_도구선택6단계.md를 읽고, 핵심을 다섯 줄로 정리해 줘. 파일은 고치지 마.
```

**메시지 2**

```text
업무목록_샘플.csv의 업무 12개를 예시기준_데이터등급.md와 예시기준_도구선택6단계.md에 따라 분류해서 업무분류표_샘플.md 파일로 저장해 줘.
- 열: 번호, 업무, 데이터 등급, 등급 근거(한 줄), 멈춘 단계, 알맞은 도구, 사람이 확인할 점
- "다루는 자료" 열을 보고 등급을 정해. 여러 자료가 섞이면 가장 높은 등급으로.
- 등급이나 단계가 애매하면 지어내지 말고 "판단 필요"라고 적어 줘.
- 표 아래에 등급별 업무 수를 한 줄로 요약해 줘.
```

**메시지 3**

```text
업무분류표_샘플.md 7번 업무는 신청자 이름이 들어 있으니 민감 등급으로 바꾸고, 멈춘 단계는 1단계, 알맞은 도구는 "AI 도구에 넣지 않음"으로 고쳐 줘. 다른 행은 그대로 둬.
```

**메시지 4**

```text
업무분류표_샘플.md에서 "판단 필요"이거나 사람이 다시 확인해야 하는 업무만 모아, 각 업무마다 정보보안 담당자에게 물어볼 질문을 한 줄씩 써서 확인질문_정보보안.md로 저장해 줘.
```

**메시지 5**

```text
내가 직접 쓸 내업무분류표_양식.md를 만들어 줘.
- 맨 위에 "업무 설명만 적고, 실제 자료는 붙여 넣지 않는다"는 주의 문구
- 업무분류표_샘플.md와 같은 열의 빈 표 10행
- 표 위에 작성 요령 3줄, 표 첫 행에 가상의 예시 1행
- 맨 아래에 "이 기준은 예시이며 회사 정보보안 규정을 따른다"는 문구
```
