# 대본 검토 체크리스트 (11강 시연·실습용)

- [ ] 낭독문 글자 수가 공백 포함 4,000~4,500자인가 (제목·큐 줄·메모 줄 제외, **프로그램으로 셈**)
- [ ] 도입·개념·시연·정리 네 구간이 있고, 구간 분량이 대략 300·1,100·2,200·500자인가
- [ ] 강의계획서의 해당 차시 학습목표가 도입에서 그대로 제시되는가
- [ ] 낭독문에 기호·영문·셀 주소·괄호 설명이 남아 있지 않은가 (낭독표기규칙.md)
- [ ] 화면에 띄울 수식은 큐 줄에만 있는가
- [ ] [화면: 단계 n] 큐가 빠짐없이 번호 순서대로 있는가
- [ ] 예제 데이터가 새로 만든 가상 자료인가 (기출문제 원문 인용·흉내 없음) ← **사람이 직접 확인**
- [ ] 강의계획서에 없는 시험 정보를 사실처럼 말하지 않는가
