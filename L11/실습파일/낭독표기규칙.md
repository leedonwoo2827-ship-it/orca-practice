# 낭독 표기 규칙 (음성 합성용 대본)

> 대본의 **낭독문**에만 적용한다. `[슬라이드 n]`, `[화면: …]` 큐 줄과 `> 메모:` 줄은 화면용이라 그대로 둔다.

## 1. 기본
| 규칙 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 한 문장은 한 호흡, 40자 안팎 | 길게 이어지는 복문 | 두 문장으로 끊기 |
| 괄호 설명 금지 | IF(조건 함수)를 씁니다 | 조건에 따라 값을 고르는 이프 함수를 씁니다 |
| 기호·경로·영문 약어 금지 | >=, %, A3:A20, LMS | 크거나 같다, 퍼센트, 에이삼부터 에이이십, 학습관리시스템 |
| 범위 숫자는 읽는 말로 | 1~2개, 4,000~4,500자 | 한두 개, 사천에서 사천오백 자 |
| 존댓말 "~합니다" | ~함, ~임 | ~합니다 |

## 2. 셀 주소
| 화면 | 낭독 |
|---|---|
| A3 | 에이삼 |
| B12 | 비십이 |
| A3:A20 | 에이삼부터 에이이십 |
| $A$3 | 절대 참조 에이삼 (또는 "에이삼을 고정해") |
| D열 | 디 열 |

## 3. 함수 이름
| 화면 | 낭독 |
|---|---|
| IF | 이프 |
| AND / OR | 앤드 / 오어 |
| VLOOKUP | 브이룩업 |
| IFERROR | 이프에러 |
| INDEX / MATCH | 인덱스 / 매치 |
| LEFT / MID | 레프트 / 미드 |
| CHOOSE | 추즈 |
| ROUND | 라운드 |
| AVERAGE | 애버리지 |

## 4. 기호
| 화면 | 낭독 |
|---|---|
| = (수식 시작) | 등호로 시작해 |
| >= / <= | 크거나 같다 / 작거나 같다 |
| <> | 같지 않다 |
| "합격" | 큰따옴표 안에 합격 (필요할 때만) |
| , (인수 구분) | 쉼표 |
| % | 퍼센트 |
