# 지시문: 차시 대본 (11강 시연용, 복사해서 에이전트 입력창에 붙여 넣기)

강의계획서_컴활1급실기엑셀.md의 2차시(계산작업, 함수 중첩으로 등급 구하기)를 15분 분량의 낭독 대본으로 써 줘.

[만들 파일]
- 파일 이름: 대본_02_함수중첩.md

[구성과 분량] 낭독문만 세며, 공백 포함 전체 4,000~4,500자
- 도입 약 300자: 오늘 배울 장면, 학습목표
- 개념 약 1,100자: 조건이 늘 때 IF를 겹쳐 쓰는 원리, AND·OR, VLOOKUP과 IFERROR
- 시연 약 2,200자: 예제 2개를 엑셀 화면에서 단계별로 푸는 설명
- 정리 약 500자: 요약 3줄, 실습 안내, 다음 차시 예고

[표기 형식]
- 구간 제목은 "## 도입"처럼 쓴다.
- 슬라이드는 [슬라이드 n], 엑셀 화면 조작은 [화면: 단계 n] 줄로 따로 쓴다.
- 화면에 띄울 수식은 [화면: …] 줄 안에만 쓰고, 낭독문에는 말로 풀어 쓴다.
- 낭독문은 낭독표기규칙.md를 따른다.

[지켜야 할 것]
- 예제 데이터는 새로 만든 가상의 "온라인 강좌 운영표"를 쓴다. 기출문제 원문을 인용하거나 흉내 내지 않는다.
- 강의계획서에 없는 시험 정보(배점, 문항 수 등)를 사실처럼 말하지 않는다.
- 다 쓰면 낭독문 글자 수를 파이썬으로 세어 구간별로 알려 준다.
