## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
강의계획서_컴활1급실기엑셀.md의 2차시(계산작업, 함수 중첩으로 등급 구하기)를 15분 분량의 낭독 대본으로 써 줘.

[만들 파일]
- 파일 이름: 대본_02_함수중첩.md

[구성과 분량] 낭독문만 세며, 공백 포함 전체 4,000~4,500자
- 도입 약 300자: 오늘 배울 장면, 학습목표
- 개념 약 1,100자: 조건이 늘 때 IF를 겹쳐 쓰는 원리, AND·OR, VLOOKUP과 IFERROR
- 시연 약 2,200자: 예제 2개를 엑셀 화면에서 단계별로 푸는 설명
- 정리 약 500자: 요약 3줄, 실습 안내, 다음 차시 예고

[표기 형식]
- 구간 제목은 "## 도입"처럼 쓴다.
- 슬라이드는 [슬라이드 n], 엑셀 화면 조작은 [화면: 단계 n] 줄로 따로 쓴다.
- 화면에 띄울 수식은 [화면: …] 줄 안에만 쓰고, 낭독문에는 말로 풀어 쓴다.
- 낭독문은 낭독표기규칙.md를 따른다.

[지켜야 할 것]
- 예제 데이터는 새로 만든 가상의 "온라인 강좌 운영표"를 쓴다. 기출문제 원문을 인용하거나 흉내 내지 않는다.
- 강의계획서에 없는 시험 정보(배점, 문항 수 등)를 사실처럼 말하지 않는다.
- 다 쓰면 낭독문 글자 수를 파이썬으로 세어 구간별로 알려 준다.
```

**메시지 2**

```text
대본_02_함수중첩.md의 낭독문 글자 수를 세어 줘.
- 기준: "#"으로 시작하는 제목 줄, "["로 시작하는 큐 줄, ">"로 시작하는 메모 줄, 빈 줄은 빼고, 공백은 포함해서 센다.
- 반드시 파이썬으로 세고, 쓴 코드도 보여 줘.
- 도입·개념·시연·정리 구간별 글자 수와 합계를 표로 보여 줘. 기준은 300·1,100·2,200·500, 합계 4,000~4,500.
```

**메시지 3**

```text
낭독표기규칙.md 기준으로 대본_02_함수중첩.md의 낭독문만 점검해 줘. 큐 줄과 메모 줄은 그대로 둬.
1. 남아 있는 영문, 기호, 숫자 범위, 셀 주소, 함수 이름, 괄호 설명을 모두 찾아서 "문장 / 문제 표기 / 바꿀 표기" 표로 먼저 보여 줘.
2. 표를 보여 준 다음, 규칙대로 모두 고쳐 줘.
```

**메시지 4**

```text
대본검토체크리스트.md의 항목으로 대본_02_함수중첩.md를 점검해서 "항목 / 결과 / 근거" 표로 보여 줘. 고치지는 마.
기출 원문 항목은 네가 판단하지 말고 "사람 확인 필요"로 표시해 줘.
```
