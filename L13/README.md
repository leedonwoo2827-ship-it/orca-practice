## 과제

자신의 업무 분야에서 자주 잘못 읽힐 말 10개를 발음 사전에 보태고, 대본 한 문단으로 낭독본·자막·시험 음성을 만들어 들어 보시오.

> 영상에서는 이 파일들을 `D:\orca-practice\02-컴활1급강의` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
대본_02_함수중첩.md를 음성 합성 프로그램(슈퍼토닉)에 넣을 낭독본으로 바꿔 줘.

[만들 파일]
- 낭독_02_함수중첩.txt (UTF-8)

[규칙]
1. "#" 제목 줄, "[" 큐 줄, ">" 메모 줄은 모두 뺀다. 낭독문만 남긴다.
2. 한 줄에 한 문장. 구간(도입·개념·시연·정리)이 바뀌는 곳에는 빈 줄 하나.
3. 발음사전_컴활.csv의 "화면표기 → 낭독표기"를 적용한다. 사전에 없는데 영문·숫자·기호가 남은 곳은 바꾸지 말고 목록으로 따로 보여 줘.
4. 숫자는 읽는 대로 한글로 쓴다. (예: 4.5 → 사 점 오, 2차시 → 이 차시)
5. 문장 내용은 바꾸지 않는다. 표기만 바꾼다.
6. 끝나면 바꾼 곳을 "원래 표기 / 바꾼 표기 / 횟수" 표로 보여 줘.
```

**메시지 2**

```text
남은 표기는 이렇게 읽어 줘.
- 2차시 → 이 차시, 3차시 → 삼 차시
- 20자 → 이십 자
- 엘 열 → 그대로 "엘 열"
낭독_02_함수중첩.txt에 적용하고, 발음사전_컴활.csv에도 새 줄로 보태 줘. 구분과 비고 칸도 채워 줘.
```

**메시지 3**

```text
대본_02_함수중첩.md의 낭독문으로 자막 파일을 만들어 줘.

[만들 파일]
- 자막_02_함수중첩.srt (UTF-8)

[규칙]
1. 자막에는 화면 표기를 쓴다. 낭독문의 읽는 말을 발음사전_컴활.csv의 "낭독표기 → 화면표기"로 되돌린다. (예: 브이룩업 → VLOOKUP, 에이치이 → H2)
2. 자막 한 개는 한 문장, 최대 두 줄, 한 줄은 20자 안팎. 긴 문장은 의미 단위로 나눈다.
3. 시간은 글자 수로 추정한다. 낭독본 기준 초당 4.8자(1분 약 290자). 자막 한 개는 최소 1.2초, 자막 사이 간격 0.2초, 구간이 바뀌면 0.8초 쉰다.
4. 시간 계산은 파이썬으로 하고, 전체 예상 길이(분:초)를 알려 줘.
```

**메시지 4**

```text
슈퍼토닉(Supertonic)으로 낭독_02_함수중첩.txt를 음성 파일로 만들어 줘. 이 컴퓨터에는 그래픽 카드가 없으니 CPU로 실행해야 해.
1. 먼저 슈퍼토닉 공식 저장소나 공식 문서에서 설치·실행 방법을 찾아서, 무엇을 설치할지 요약해서 보여 줘. 내가 확인한 다음에 설치해.
2. 한국어 음성을 지원하는지, 라이선스가 어떤지 공식 문서 기준으로 알려 줘.
3. 설치가 끝나면 낭독본의 처음 세 줄만 시험으로 만들어 줘: 시험_02.wav
4. 내가 들어 보고 괜찮다고 하면 전체를 낭독_02_함수중첩.wav로 만들어 줘. 문장별로 나눠 만든 뒤 이어 붙여도 돼.
```

**메시지 5**

```text
공식 주소에서 받는 게 맞으니 진행해 줘. 설치 명령은 하나씩 실행해 줘.
```

**메시지 6**

```text
시험 음성 괜찮아. 전체를 낭독_02_함수중첩.wav로 만들어 줘. 문장별로 만들어서 이어 붙이고, 문장 사이에는 0.3초, 빈 줄(구간 바뀜)에는 0.8초 쉼을 넣어 줘.
```

**메시지 7**

```text
낭독_02_함수중첩.wav의 실제 길이를 재서, 자막_02_함수중첩.srt의 시간을 실제 길이에 맞게 비율로 늘이거나 줄여 줘.
- 예상 길이, 실제 길이, 적용한 비율을 알려 줘.
- 원래 파일은 두고 자막_02_함수중첩_보정.srt로 저장해 줘.
```
