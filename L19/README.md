# 19강 · 봇을 동료에게 공개

**Orca로 일하는 법** · 5. 확산

- 이번 강에서 할 수 있게 되는 것: 공개 범위·권한·데이터 등급을 점검하고 봇을 공개한다
- 실습 결과물: 공개 체크리스트

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 실습 파일 (`실습파일/`)

- `L19_공개전_봇지시문.md`
- `L19_공개체크리스트_양식.md`
- `L19_데이터등급_예시정책.md`
- `L19_봇설정_현황.md`

## 예시 결과 (`예시결과/`, 4개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

내가 만든 봇 1개를 골라 공개 체크리스트 12항목으로 점검하고, "조치 필요" 항목을 모두 해결한 뒤 동료 1명에게 공개하시오.

> 영상에서는 이 파일들을 `D:\orca-practice\04-확산` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
L19_공개전_봇지시문.md 의 봇을 팀원 7명(다른 팀 인턴 1명 포함)에게 공개하려고 해.
L19_공개전_봇지시문.md 와 L19_봇설정_현황.md 를 L19_데이터등급_예시정책.md 에 비춰 보고, 공개 위험 점검표를 만들어서 공개위험점검_팀도우미봇.md 로 저장해 줘.

- 열: 번호, 위험, 근거(파일 이름과 해당 줄), 위험 종류(공개 범위 / 접근 범위 / 데이터 등급 / 권한 / 외부 발송 / 커넥터 / 운영), 심각도(상/중/하), 고칠 방법
- 고칠 방법에는 "지시문에서 고칠 것"과 "사람이 Orca 설정에서 바꿀 것"을 구분해서 적어
- 참고: 이 봇을 공개하면 요청한 동료도 봇 주인의 권한으로 봇을 움직인다
- 파일은 아무것도 고치지 마
```

**메시지 2**

```text
공개위험점검_팀도우미봇.md 의 "지시문에서 고칠 것"대로 L19_공개전_봇지시문.md 를 고쳐 줘.

- 위험한 할 일 줄은 지우거나 안전하게 바꾼다
- [지켜야 할 것]에 다음 내용을 넣는다: 봇 폴더 밖은 읽거나 고치지 않는다 / 개인정보와 금액은 다루지 않는다 / 파일을 지우지 않는다 / 외부로 보내지 않고 발송은 사람이 한다
- 금지된 요청을 받으면 이유를 짧게 밝히고 거절한 뒤 "봇 주인에게 문의해 주세요"라고 안내한다
- 맨 위 "공개 전 버전" 안내 문구는 "공개용 버전"으로 바꾼다
```

**메시지 3**

```text
L19_공개체크리스트_양식.md 의 12개 항목을, 고친 L19_공개전_봇지시문.md 와 L19_봇설정_현황.md 기준으로 채워서 공개체크리스트_팀도우미봇.md 로 저장해 줘.

- 결과는 "통과" 또는 "조치 필요"
- 설정 메모가 아직 바뀌지 않았으면 "조치 필요"로 두고, 사람이 Orca에서 바꿀 내용을 구체적으로 적어
- 맨 아래에 "사람이 할 일" 목록을 따로 정리해
```

```text
고친 L19_공개전_봇지시문.md 를 따르는 봇이라고 가정하고, 동료가 아래 세 가지를 요청했을 때 봇이 어떻게 답할지 동료요청_시뮬레이션.md 로 저장해 줘. 요청마다 답변 문장과, 지시문의 어느 줄 때문에 그렇게 답하는지 적어.
```
