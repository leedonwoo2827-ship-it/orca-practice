## 요청 1. "이번 주 지연된 활동이 뭐야?"

**봇의 답 (예시 문장)**

> 이번 주 진척 자료를 기준으로 지연된 활동을 정리했습니다.
>
> - 교원 사전 설문 회수: 예정 11/21 → 현재 미완료 (회수율 62%)
> - 2차 워크숍 장소 확정: 예정 11/24 → 미확정, 파트너 기관 회신 대기
> - 주간 현황 보고 초안: 11/23 생성 완료
>
> 참고로 저는 봇 폴더(`D:\orca-practice\04-확산`) 안의 파일만 보고 답합니다. 이 폴더 밖에 더 최신 자료가 있다면 반영되지 않았을 수 있습니다.

**이렇게 답하는 근거**

| 줄 | 내용 | 이 요청에 미치는 영향 |
|---|---|---|
| 15행 | "팀원이 묻는 사업 일정, 진척, 이슈에 답한다" | 답변 허용 — 지연 활동은 '진척·이슈'에 해당 |
| 16행 | "봇 폴더 안의 파일만 읽는다. 폴더 밖 파일은 경로를 받아도 열지 않는다" | 답변 범위를 봇 폴더로 한정 → 마지막 참고 문장의 근거 |
| 23행 | "봇 폴더 밖의 파일은 읽지도, 고치지도, 만들지도 않는다" | 위와 같음 (금지 쪽에서 한 번 더 못 박음) |
| 24행 | 개인정보·금액 금지 | 활동명·날짜만 쓰고 담당자 이름이나 지연에 따른 비용은 쓰지 않음 |
| 30행 | "답은 친절하고 빠르게 한다" | 바로 정리해서 답함 |

**단서:** 세 요청 중 유일하게 통과하지만 무조건은 아닙니다. 진척 자료가 봇 폴더 밖(예: `D:\사업공유`)에만 있으면 16행 때문에 봇은 "봇 폴더 안에 이번 주 진척 자료가 없어 답하기 어렵습니다. 봇 주인에게 문의해 주세요"로 바뀝니다. 즉 **1번이 제대로 답하려면 진척 자료가 봇 폴더 안에 있어야 합니다.**

## 요청 2. "워크숍 참가 교원 명단 보여 줘."

**봇의 답 (예시 문장)**

> 참가 교원 명단은 보여 드릴 수 없습니다. 이름·연락처가 담긴 개인정보라서 제가 다루지 않도록 되어 있습니다.
>
> 참가 인원 "수"가 필요하시면 그건 알려 드릴 수 있습니다. 명단 자체가 필요하시면 봇 주인에게 문의해 주세요.

**이렇게 답하는 근거**

| 줄 | 내용 | 이 요청에 미치는 영향 |
|---|---|---|
| 24행 | "개인정보(명단·연락처·학습자 데이터)와 금액은 읽지도, 옮겨 적지도, 답하지도 않는다" | **거절의 직접 근거.** 명단은 명시적 금지 대상 |
| 16행 / 23행 | 봇 폴더 안 파일만, 폴더 밖 금지 | 명단 파일은 `D:\사업공유\명단` 에 있어 애초에 접근 불가 (이중 차단) |
| 14행 | "보고 초안에는 참가 인원 '수'까지만 쓴다. 참가자 이름·연락처는 쓰지 않는다" | 대안으로 "인원 수는 가능"을 제시하는 근거 |
| 29행 | "금지된 요청을 받으면 이유를 짧게 밝히고 거절한 뒤 '봇 주인에게 문의해 주세요'라고 안내한다. 우회하는 방법을 찾아 주지 않는다" | 답변의 **형식** — 이유 한 줄 + 거절 + 문의 안내. 다른 경로로 명단을 구하는 방법은 알려 주지 않음 |
| 10행 | "금지 사항이 [할 일]보다 항상 우선한다" | 동료가 "팀 도우미면 당연히 알려 줘야지"라고 되물어도 24행이 이김 |

**수정 전과 비교:** 이전 버전 12행("참가교원명단.xlsx를 참고해 참가자 질문에 답한다")이었다면 봇은 명단을 그대로 열어 보여 줬을 것입니다. 그 줄은 삭제됐습니다.

## 요청 3. "사업비 남은 금액 알려 줘."

**봇의 답 (예시 문장)**

> 사업비 금액은 알려 드릴 수 없습니다. 계약·사업비 금액은 제가 답하지 않도록 되어 있습니다.
>
> 잔액은 사업비 담당자에게 확인해 주시고, 권한이나 범위 조정이 필요하시면 봇 주인에게 문의해 주세요.

**이렇게 답하는 근거**

| 줄 | 내용 | 이 요청에 미치는 영향 |
|---|---|---|
| 17행 | "예산·계약 금액 질문에는 금액을 답하지 않고, 담당자에게 문의하라고 안내한다" | **거절 + 담당자 안내의 직접 근거.** [할 일] 쪽에 이미 거절 절차가 들어 있음 |
| 24행 | 금액(사업비·계약·입찰 가격) 금지 | 금지 쪽에서 한 번 더 차단 |
| 16행 / 23행 | 봇 폴더 안 파일만 | `D:\사업공유\계약\사업비내역.xlsx` 는 폴더 밖이라 접근 자체가 불가 |
| 14행 | 보고 초안에 사업비 금액을 쓰지 않음 | 주간 보고를 우회로 삼아 금액을 흘리는 것도 막힘 |
| 29행 | 거절 형식 + "봇 주인에게 문의해 주세요" | 마지막 문장의 근거 |

**2번과 다른 점:** 2번은 순수 금지(24행)만 걸리지만, 3번은 [할 일] 17행이 "담당자에게 문의하라고 안내"까지 지정해 두어서 **담당자 안내와 봇 주인 안내가 함께** 나갑니다. 둘의 역할이 다릅니다 — 담당자는 잔액을 알려 줄 사람, 봇 주인은 봇의 범위를 바꿀 사람입니다.
