# 데이터 등급 예시 정책 (가상 회사 "새솔에듀" 기준, 실습용)

> 실제 회사의 정책이 아닙니다. 여러분 회사의 실제 정책을 먼저 확인하세요.

| 등급 | 예 | 개인 봇(나만 사용) | 팀 공개 봇 |
|---|---|---|---|
| 공개 | 보도자료, 공개 웹 자료, 공고문 | 허용 | 허용 |
| 사내 일반 | 회의록, 내부 공지, 제안서 초안, 주간 현황 | 허용 | 허용 |
| 사내 제한 | 계약서, 사업비·입찰 가격, 인사 평가 | 승인 받은 경우만 | 금지 |
| 민감 | 개인정보(명단·연락처), 학습자 데이터, 고객 데이터 | 금지 | 금지 |

- 외부 발송(메일·메신저로 회사 밖에 보내기)은 등급과 관계없이 사람이 한다.
- 등급이 애매하면 한 단계 높은 등급으로 본다.
