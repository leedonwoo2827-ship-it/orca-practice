# 10강 · 커리큘럼 설계

**Orca로 일하는 법** · 3. 컴활 1급 실기 강의 제작

- 이번 강에서 할 수 있게 되는 것: 과정 기본정보로 시험 영역별 차시 계획을 만들고 검토한다
- 실습 결과물: 강의계획서

## 따라 하는 순서

1. `실습파일/` 의 파일을 내 실습 폴더에 복사하고 Orca 에서 그 폴더를 엽니다.
2. 아래 「영상에서 보낸 채팅 메시지」를 차례로 보냅니다.
3. 에이전트가 만든 결과를 `예시결과/` 와 비교해 봅니다. 답은 매번 조금씩 다르니 형식과 빠진 곳 위주로 봅니다.
4. `과제.md` 를 내 업무로 해 봅니다.

## 예시 결과 (`예시결과/`, 1개)

영상을 녹화할 때 에이전트가 실제로 만든 파일입니다. 정답이 아니라 참고용 예시입니다.

## 과제

부서에서 최근 받은 과정 요청 1건으로 과정정보 파일을 만들고, 지시문을 고쳐 강의계획서 초안을 만든 뒤 체크리스트로 검토하시오. (실제 수강생 정보·기출 원문 입력 금지)

> 영상에서는 이 파일들을 `D:\orca-practice\02-컴활1급강의` 폴더에 넣고 Orca 에서 그 폴더를 열었습니다. 다른 위치에 두어도 됩니다. 채팅 메시지 속 경로만 내 폴더 경로로 바꿔 보내세요.

## 영상에서 보낸 채팅 메시지

그대로 복사해 보내도 됩니다. 에이전트의 답은 매번 조금씩 다릅니다.

**메시지 1**

```text
과정정보_컴활1급실기엑셀.md 파일을 읽고 강의계획서를 만들어 줘.

[만들 파일]
- 파일 이름: 강의계획서_컴활1급실기엑셀.md

[들어갈 내용]
1. 과정 목표 3개. "수강 후 ~할 수 있다" 형태로, 관찰 가능한 동사로 쓴다.
2. 차시 계획표 10행. 열은 차시, 시험 영역, 차시명, 학습목표, 핵심 기능, 실습 파일, 정답 파일.
3. 영역별 배점과 배정 차시 수를 나란히 보여 주는 표.
4. 요구사항 4개가 각각 어느 차시에 반영됐는지 대응표.

[지켜야 할 것]
- 시험 기준 버전에 없는 기능은 넣지 않는다.
- 기출문제 원문을 인용하거나 흉내 내지 않는다. 실습 문제는 "자사 재집필"로 표시만 한다.
- 과정정보 파일에 없는 사실(시험 일정, 응시료, 문항 수 등)은 지어내지 말고 맨 끝 "확인 필요" 목록에 적는다.
```

